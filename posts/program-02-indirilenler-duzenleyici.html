Batch Uygulamaları

İndirilenler klasöründeki dağınık dosyaları resim, belge, video, müzik, arşiv ve program klasörlerine ayıran batch programı.

İçindekiler
  1. Nasıl kullanılır?
  2. Kod nasıl çalışıyor?
  3. Özelleştirme

İndirilenler klasörü zamanla yüzlerce dosyayla dolar. Bu program her dosyayı uzantısına göre ilgili alt klasöre (Resimler, Belgeler, Videolar...) taşır. Çalıştırmadan önce onay ister, aynı adlı dosya varsa üzerine yazmaz, en sonda kaç dosya taşıdığını söyler.

Nasıl kullanılır?

  1. Kodu duzenle.bat adıyla kaydedin. Dosyayı herhangi bir yere koyabilirsiniz; kendisi taşınmaz.
  2. Çift tıklayın. Onay sorusuna E ile cevap verin.
  3. Başka bir klasörü düzenlemek isterseniz KLASOR ayarını değiştirin.
@echo off
setlocal
title Indirilenler Duzenleyici

rem ===== AYARLAR =====
set "KLASOR=%USERPROFILE%\Downloads"
rem ===================

set "TOPLAM=0"
cd /d "%KLASOR%" 2>nul || goto :klasor_yok

echo Duzenlenecek klasor:
echo %KLASOR%
echo.
choice /c EH /n /m "Dosyalar alt klasorlere tasinacak. Devam edilsin mi? (E/H) "
if errorlevel 2 goto :iptal
echo.

call :tasi Resimler jpg jpeg png gif webp bmp svg
call :tasi Belgeler pdf doc docx xls xlsx ppt pptx txt csv
call :tasi Videolar mp4 mkv avi mov wmv
call :tasi Muzikler mp3 wav flac m4a
call :tasi Arsivler zip rar 7z tar gz
call :tasi Programlar exe msi

echo.
echo Toplam %TOPLAM% dosya tasindi.
pause
exit /b 0

:klasor_yok
echo HATA: Klasor bulunamadi:
echo %KLASOR%
pause
exit /b 1

:iptal
echo Islem iptal edildi, hicbir dosya tasinmadi.
pause
exit /b 0

rem ---- Alt program: tasi KLASOR_ADI uzanti1 uzanti2 ... ----
:tasi
set "ALT=%~1"
shift
:dongu
if "%~1"=="" exit /b
for %%f in (*.%~1) do (
    if exist "%ALT%\%%f" (
        echo Atlandi, ayni adda dosya var: %%f
    ) else (
        if not exist "%ALT%\" md "%ALT%"
        move "%%f" "%ALT%\" >nul
        echo Tasindi: %%f  ^>  %ALT%
        set /a TOPLAM+=1
    )
)
shift
goto :dongu

Kod nasıl çalışıyor?

  • cd /d "%KLASOR%": Düzenlenecek klasöre geçer. Klasör yoksa || sayesinde :klasor_yok bölümüne atlar.
  • choice /c EH /n /m "...": Yalnızca E veya H tuşunu kabul eder. E 1, H 2 sonucunu verir; bu yüzden önce errorlevel 2 (H) kontrol edilir.
  • call :tasi Resimler jpg png ...: İlk değer klasör adı, geri kalanlar uzantılardır. Alt program shift ile ilk değeri atıp uzantıları teker teker işler (5. derste anlatılan yöntem).
  • if exist "%ALT%\%%f": Hedefte aynı adlı dosya varsa üzerine yazmaz, atlar ve haber verir.
  • set /a TOPLAM+=1: Taşınan dosya sayısını sayar. Sayaç döngü içinde güncellendiği için sonda %TOPLAM% ile yazdırılır.

Özelleştirme

  • Yeni bir tür eklemek için bir call :tasi satırı yazın. Örnek: call :tasi Yazilar epub mobi.
  • txt dosyalarını taşımak istemiyorsanız Belgeler satırından txt kelimesini silin.
  • Bu script'i Masaüstünü düzenlemek için de kullanabilirsiniz: set "KLASOR=%USERPROFILE%\Desktop".
Dikkat: Dosyalar silinmez, yalnızca taşınır. Yine de ilk kullanımda önemli bir klasörde değil, sınama amaçlı birkaç dosyayla denemen önerilir. İndirmesi süren dosyalar (.crdownload, .part) listede olmadığı için taşınmaz.

Batch Rehberi

tasklist, taskkill, start, sc ve net komutlarıyla programları başlatma, süreçleri listeleme ve sonlandırma, hizmetleri yönetme.

İçindekiler
  1. Program başlatma: start
  2. Süreçleri listeleme: tasklist
  3. Süreç sonlandırma: taskkill
  4. Hizmetler: sc ve net
  5. Çıkış koduna göre işlem
  6. Özet

Batch betikleri yalnızca dosya işlemleri için değil, programları başlatmak, çalışan süreçleri denetlemek ve Windows hizmetlerini yönetmek için de kullanılır. Bu yazıda ilgili komutlar ve dikkat edilecek noktalar verilir.

Program başlatma: start

start notepad                          rem programi ayri pencerede baslatir, betik devam eder
start "" "C:\Program Files\Uygulama\uygulama.exe"
start "" https://example.com           rem varsayilan tarayicida acar
start "" "C:\Belgeler"                 rem klasoru Gezgin'de acar
start /wait notepad                    rem program kapanana kadar betik bekler
start /min notepad                     rem simge durumunda baslatir
start /b komut                         rem yeni pencere acmadan arka planda calistirir
  • start komutunda ilk tırnaklı ifade pencere başlığı sayılır. Yol tırnak içinde verilecekse önüne boş başlık ("") konulmalıdır.
  • start /wait olmadan betik, başlattığı programı beklemeden sonraki satıra geçer.
  • Başka bir betiği çalıştırmak için call betik.bat, yeni pencerede çalıştırmak için start "" betik.bat kullanılır.

Süreçleri listeleme: tasklist

tasklist                                   rem tum surecler
tasklist /fi "imagename eq chrome.exe"     rem ada gore filtre
tasklist /fi "memusage gt 500000"          rem 500 MB'tan fazla bellek kullananlar
tasklist /svc                              rem sureclerdeki hizmetleri gosterir
tasklist /fo csv /nh                       rem CSV bicimi, basliksiz

Bir programın çalışıp çalışmadığı şu şekilde denetlenir:

@echo off
tasklist /fi "imagename eq notepad.exe" | find /i "notepad.exe" > nul
if %errorlevel%==0 (
    echo Notepad calisiyor.
) else (
    echo Notepad calismiyor.
)
pause
tasklist eşleşme bulamazsa da hata kodu 0 döndürür; bu nedenle sonuç find ile süzülerek denetlenir.

Süreç sonlandırma: taskkill

taskkill /im notepad.exe          rem ada gore, nazikce kapatmayi dener
taskkill /f /im notepad.exe       rem zorla sonlandirir (kaydedilmemis veri kaybolur)
taskkill /pid 1234                rem surec numarasina gore
taskkill /f /t /im uygulama.exe   rem alt surecleriyle birlikte sonlandirir
taskkill /fi "status eq not responding" /f   rem yanit vermeyenleri sonlandirir
  • /f olmadan program kapanma isteğini işleyebilir; kaydedilmemiş veriler için kullanıcıya soru sorabilir.
  • /f ile sonlandırılan süreç veri kaydetme şansı bulamaz.
  • Sistem süreçleri ve yönetici yetkisiyle çalışanlar için betiğin yönetici olarak çalıştırılması gerekir.
@echo off
echo Tarayici kapatiliyor...
taskkill /im chrome.exe > nul 2>&1
if errorlevel 1 (echo Chrome zaten kapali.) else (echo Kapatildi.)
pause

Hizmetler: sc ve net

KomutAçıklamaYönetici?
sc queryÇalışan hizmetleri listelerHayır
sc query hizmetadiTek hizmetin durumuHayır
sc qc hizmetadiHizmet yapılandırması (başlangıç türü, yolu)Hayır
net startÇalışan hizmetlerin görünen adlarını listelerHayır
net start hizmetadiHizmeti başlatırEvet
net stop hizmetadiHizmeti durdururEvet
sc config hizmetadi start= demandBaşlangıç türünü değiştirir (auto, demand, disabled). start= sonrasında boşluk gerekir.Evet
 
@echo off
sc query Spooler | find "RUNNING" > nul
if %errorlevel%==0 (
    echo Yazdirma biriktirici calisiyor, yeniden baslatiliyor...
    net stop Spooler
    net start Spooler
) else (
    echo Yazdirma biriktirici durmus, baslatiliyor...
    net start Spooler
)
pause

sc komutlarında hizmetin kısa adı (örneğin Spooler), net komutlarında hem kısa ad hem görünen ad kullanılabilir. Kısa ad sc query çıktısındaki SERVICE_NAME satırından öğrenilir.

Hizmet başlatma ve durdurma işlemleri yönetici yetkisi ister. Betiğin yönetici olarak çalıştığını denetleyen kod için Dağıtım ve Yönetici Yetkisi yazısına bakılabilir.

Çıkış koduna göre işlem

start /wait "" kurulum.exe /sessiz
if errorlevel 1 (
    echo Kurulum basarisiz. Cikis kodu: %errorlevel%
    exit /b 1
)
echo Kurulum tamamlandi.

Programların çıkış kodu anlamları programa göre değişir; genellikle 0 başarıyı gösterir. Hata kodu yönetimi için Hata Yönetimi ve Log Tutma yazısına bakılabilir.

Özet

  • start programı başlatır; /wait bitmesini bekler, yol tırnaklı ise önüne "" konur.
  • tasklist listeler, find ile denetim yapılır; taskkill /f zorla sonlandırır.
  • Hizmetler sc query ile sorgulanır, net start ve net stop ile yönetilir (yönetici gerekir).

Batch Uygulamaları

Rastgele karakter dizileriyle bir şifreyi karakter karakter çözüyormuş görünümü veren, filmlerdeki şifre kırma sahnelerini taklit eden batch programı.

  2. Kod nasıl çalışıyor?
  3. Özelleştirme

Bu program, önceden belirlenen bir hedef metni rastgele karakterlerden başlayarak adım adım "çözüyormuş" gibi gösterir; filmlerdeki şifre kırma sahnelerine benzer bir görünüm oluşturur.

Önemli: Bu program tamamen görsel bir gösteridir; hiçbir dosyayı silmez, hiçbir ayarı değiştirmez ve internete bağlanmaz. Yalnızca ekran yazısını, rengini ve bir pencere başlığını değiştirir; pencereyi kapattığında bilgisayarında hiçbir iz kalmaz. Şaka amaçlı kullanırken karşındaki kişiyi gerçekten korkutmamaya dikkat et.

Nasıl kullanılır?

  1. Aşağıdaki kodu Not Defteri'ne yapıştır ve program-18-sahte-sifre-kirma.bat adıyla kaydet (Kayıt türü: Tüm dosyalar).
  2. Çift tıklayarak çalıştır. Kapatmak için pencereyi normal şekilde kapat veya Ctrl+C kullan.
@echo off
setlocal enabledelayedexpansion
title Sifre Cozuluyor
color 0a
cls
set "HEDEF=ERISIM-2026"
set "KARAKTER=ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789"
echo SIFRE COZME BASLATILDI
echo.
for /l %%t in (1,1,20) do (
  set "satir="
  for /l %%k in (1,1,11) do (
    set /a "idx=%random% %% 36"
    for %%c in (!idx!) do set "satir=!satir!!KARAKTER:~%%c,1!"
  )
  echo !satir!
  timeout /t 0 >nul
)
echo.
echo COZULDU: %HEDEF%
pause >nul

Kod nasıl çalışıyor?

Program 20 satır boyunca rastgele harflerden oluşan diziler üretir, sonunda gerçek "hedef" metni gösterir. Dosyanın başındaki setlocal enabledelayedexpansion satırı, döngü içindeki değişkenlerin her adımda anlık olarak güncellenmesini sağlar; bu satır olmadan !değişken! biçimi çalışmaz.

Özelleştirme

Kodun başındaki AYARLAR bölümündeki (varsa) değerleri değiştirerek metni, rengi veya hızı kendine göre ayarlayabilirsin. color 0a komutundaki ilk rakam zemin, ikinci rakam yazı rengidir (0: siyah, a: açık yeşil, b: açık camgöbeği, c: açık kırmızı, e: sarı, f: beyaz).

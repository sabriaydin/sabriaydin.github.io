Linux’ta birçok işlem komut satırından yapılır. Komut satırı ilk bakışta zor görünse de tekrar edilebilir, hızlı ve otomatikleştirilebilir olması nedeniyle en güçlü araçtır. Bu yazıda terminalin nasıl çalıştığı ve günlük kullanımı hızlandıran temel bilgiler anlatılmaktadır.

Terminal, kabuk ve komut

Üç kavram sıkça karıştırılır:

  • Terminal: Komutları yazdığınız pencere (GNOME Terminal, Konsole, xterm).
  • Kabuk (shell): Yazdığınız komutu yorumlayıp çalıştıran program (bash, zsh, fish).
  • Komut: Çalıştırılacak program veya kabuğa gömülü işlev (ls, cd, echo).

Çoğu dağıtımda varsayılan kabuk bash’tir. Terminali çoğu masaüstünde Ctrl + Alt + T ile açabilirsiniz.

İstem (prompt) nasıl okunur?

Terminalde satır başında görünen metne istem denir:

kullanici@bilgisayar:~/belgeler$
  |          |         |       |
  |          |         |       +-- $ normal kullanıcı, # root
  |          |         +---------- bulunulan dizin (~ ev dizini)
  |          +-------------------- makinenin adı
  +------------------------------- kullanıcı adı

Komut yapısı

Bir komut genellikle üç parçadan oluşur: komut adı, seçenekler (parametreler) ve argümanlar.

ls -l /etc
│  │  └── argüman  (hangi dizin)
│  └───── seçenek  (uzun biçimde listele)
└──────── komut
  • Kısa seçenekler tek tire ile yazılır: -l, birleştirilebilir: -la.
  • Uzun seçenekler çift tire ile yazılır: --all, --help.
  • Linux büyük/küçük harfe duyarlıdır: Belge ile belge farklı adlardır.
  • Boşluk içeren adlar tırnak içine alınır: cd "Belgelerim Yeni".

Komutların seçenekleri ezbere bilinmez; yerleşik yardımlar kullanılır.

Geçmiş ve takma ad (alias)

Kabuk, yazdığınız komutları ~/.bash_history dosyasında saklar.

history | tail -n 10      # son 10 komut
!150                      # geçmişteki 150. komutu çalıştır
history -c                # geçmişi temizle

Uzun komutlar için kısa adlar tanımlanabilir. Kalıcı olması için ~/.bashrc dosyasına eklenir.

alias ll='ls -alF'
alias guncelle='sudo apt update && sudo apt upgrade'
alias                     # tanımlı takma adlar
unalias ll                # takma adı kaldır
source ~/.bashrc          # değişikliği hemen uygula

Ortam değişkenleri

Ortam değişkenleri, kabuğun ve programların kullandığı ayarlardır. Değerine $ işaretiyle ulaşılır.

DeğişkenAnlamı
$HOMEEv dizini
$USERKullanıcı adı
$PATHKomutların aranacağı dizinler (iki nokta ile ayrılır)
$PWDBulunulan dizin
$LANGDil ve karakter kodlaması
echo $HOME
export EDITOR=nano                 # bu oturum için
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.bashrc

Özet

  • Terminal pencere, kabuk ise komutları çalıştıran programdır.
  • Komut yapısı: komut, seçenekler, argümanlar. Büyük/küçük harf önemlidir.
  • man ve --help en güvenilir yardım kaynaklarıdır.
  • Tab, Ctrl+R ve Ctrl+C günlük işleri hızlandırır.
  • Kalıcı ayarlar ~/.bashrc dosyasında tutulur.

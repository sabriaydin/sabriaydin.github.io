İçeriğe geç

Telefondan aktardığın yüzlerce IMG_4821.jpg dosyasını tek tek yeniden adlandırmak yerine bu programa klasörü ve ön eki söylersin; dosyalar tatil_001.jpg, tatil_002.jpg biçiminde sıralanır. Yeniden adlandırma önizleme + onay ile çalışır ve ayrıca bir geri alma dosyası (geri_al.bat) üretir; bir hata yaparsan eski adlara dönebilirsin.

Nasıl kullanılır?

  1. Kodu adlandir.bat adıyla kaydet.
  2. Çift tıkla. Klasör yolunu yaz (Gezgin adres çubuğundan kopyalayabilirsin) ya da boş bırakıp Enter'a bas; o zaman programın bulunduğu klasör kullanılır.
  3. Yeni adın başlangıcını (tatil_) ve dosya uzantısını (jpg) yaz. Önizlemeyi kontrol edip E ile onayla.
@echo off
setlocal EnableDelayedExpansion
title Toplu Yeniden Adlandirici

echo ==========================================
echo         TOPLU YENIDEN ADLANDIRICI
echo ==========================================
echo.
echo Dosyalar su bicimde adlandirilir: baslangic + sira no + uzanti
echo Ornek: tatil_001.jpg, tatil_002.jpg ...
echo.

set "KLASOR="
set /p "KLASOR=Klasor yolu (bos birakirsan bu scriptin klasoru): "
if not defined KLASOR set "KLASOR=%~dp0"
set "KLASOR=%KLASOR:"=%"
cd /d "%KLASOR%" 2>nul || goto :klasor_yok

set "ONEK="
set "UZANTI="
set /p "ONEK=Yeni adin baslangici (ornek: tatil_): "
set /p "UZANTI=Dosya uzantisi (ornek: jpg): "
if not defined UZANTI goto :eksik
set "UZANTI=%UZANTI:.=%"

echo.
echo Onizleme:
echo.
set "SAYAC=0"
for /f "delims=" %%f in ('dir /b /a-d "*.%UZANTI%" 2^>nul') do (
    if /i not "%%f"=="%~nx0" (
        set /a SAYAC+=1
        set "NO=000!SAYAC!"
        echo   %%f   yeni adi:   !ONEK!!NO:~-3!%%~xf
    )
)
if %SAYAC%==0 goto :dosya_yok

echo.
echo Toplam %SAYAC% dosya bulundu.
choice /c EH /n /m "Bu dosyalar yeniden adlandirilsin mi? (E/H) "
if errorlevel 2 goto :iptal

rem Geri alma dosyasini baslat
>"geri_al.bat" echo @echo off

set "SAYAC=0"
set "BASARILI=0"
for /f "delims=" %%f in ('dir /b /a-d "*.%UZANTI%" 2^>nul') do (
    if /i not "%%f"=="%~nx0" (
        set /a SAYAC+=1
        set "NO=000!SAYAC!"
        set "YENI=!ONEK!!NO:~-3!%%~xf"
        if exist "!YENI!" (
            echo Atlandi, bu ad zaten var: !YENI!
        ) else (
            ren "%%f" "!YENI!"
            >>"geri_al.bat" echo ren "!YENI!" "%%f"
            set /a BASARILI+=1
        )
    )
)

if %BASARILI%==0 (
    del "geri_al.bat" 2>nul
) else (
    >>"geri_al.bat" echo echo Eski adlar geri yuklendi.
    >>"geri_al.bat" echo pause
)

echo.
echo %BASARILI% dosya yeniden adlandirildi.
if %BASARILI% GTR 0 echo Geri almak istersen bu klasordeki geri_al.bat dosyasini calistir.
echo.
pause
exit /b 0

:klasor_yok
echo.
echo HATA: Klasor bulunamadi:
echo %KLASOR%
pause
exit /b 1

:eksik
echo.
echo HATA: Dosya uzantisi bos birakilamaz.
pause
exit /b 1

:dosya_yok
echo.
echo Bu klasorde .%UZANTI% uzantili dosya bulunamadi.
pause
exit /b 1

:iptal
echo.
echo Islem iptal edildi, hicbir dosya degistirilmedi.
pause
exit /b 0

Kod nasıl çalışıyor?

  • Gecikmeli genişletme: setlocal EnableDelayedExpansion ile döngü içinde değişen değerler !SAYAC! biçiminde okunur (10. ders). Bu olmadan sayaç her seferinde aynı sayıyı gösterirdi.
  • Sıfırlı numara: NO=000!SAYAC! değişkenin başına üç sıfır ekler (0007 gibi), !NO:~-3! ise sondan 3 karakteri alır (007). Böylece dosyalar Gezgin'de doğru sırada dizilir.
  • Uzantı korunur: %%~xf dosyanın gerçek uzantısını verir. jpg yazsan bile adı .JPG olan dosya adını .JPG olarak bırakır.
  • Güvenlik: Yeni ad zaten varsa (if exist) dosyanın üzerine yazmaz, atlar. Çalışan script'in kendisi de listeden çıkarılır.
  • Geri alma dosyası: Her başarılı işlemde ren "yeni" "eski" satırı geri_al.bat içine yazılır. Çalıştırınca tüm adlar eski haline döner.
  • Temizlik: Tırnaklı yol yapıştırsan bile %KLASOR:"=% tırnakları temizler, uzantıya yanlışlıkla nokta yazsan (.jpg) %UZANTI:.=% noktayı siler.

Özelleştirme

  • Üç haneli numara yerine dört hane için NO=0000!SAYAC! ve !NO:~-4! yaz. 999'dan fazla dosya varsa bunu yapmalısın.
  • Sıra numarası yerine dosyaların tümüne ön ek eklemek istersen YENI satırını set "YENI=!ONEK!%%f" yap.
  • Aynı işi alt klasörlerdeki dosyalar için yapmak istersen bu program yeterli değildir; her klasörde ayrı çalıştır.
Dikkat: Sıralama, dosya adlarının alfabetik sırasına göredir. Dosya adında ünlem işareti (!) varsa o dosya atlanabilir veya yanlış adlandırılabilir. Yeni adın başlangıcında şu karakterleri kullanma: \ / : * ? " < > |. İlk denemeni mutlaka dosyaların bir kopyası üzerinde yap.

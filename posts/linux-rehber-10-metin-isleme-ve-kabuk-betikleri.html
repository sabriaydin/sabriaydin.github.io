Linux’un en güçlü yönlerinden biri, küçük komutların birbirine bağlanarak karmaşık işleri yapabilmesidir. Çıktılar metin olduğu için bu araçlarla süzülebilir, dönüştürülebilir ve kabuk betiklerine dönüştürülerek otomatikleştirilebilir. Bu, serinin son yazısıdır.

cut, sort, uniq, wc, tr

cut -d: -f1 /etc/passwd            # ":" ayırıcıyla 1. alan (kullanıcı adları)
sort dosya.txt                      # alfabetik
sort -n sayilar.txt                 # sayısal

uniq -c                             # ardışık tekrarları say
wc -l dosya.txt                     # satır sayısı
tr a-z A-Z < dosya.txt              # küçükten büyüğe
head -n 5 dosya && tail -n 5 dosya

Örnek: En çok istek yapan ilk 5 IP adresi:

awk '{print $1}' erisim.log | sort | uniq -c | sort -nr | head -n 5

sed: akış düzenleyici

sed 's/eski/yeni/' dosya.txt          # her satırda ilk eşleşmeyi değiştir
sed 's/eski/yeni/g' dosya.txt         # tümünü değiştir
sed -i 's/eski/yeni/g' dosya.txt      # dosyanın kendisinde değiştir (önce yedek alın)
sed -i.bak 's/a/b/g' dosya.txt        # yedek (.bak) bırakarak
sed '/^#/d' ayar.conf                 # yorum satırlarını sil
sed -n '5,10p' dosya.txt              # 5-10. satırları yazdır

awk: sütun işleme

awk, satırları alanlara bölerek işler. $1 ilk alan, $0 tüm satırdır.

awk '{print $1, $3}' dosya.txt              # 1. ve 3. sütun
awk -F: '{print $1}' /etc/passwd          # ayırıcı ":"
awk '$3 > 100' veri.txt                  # 3. sütun 100’den büyük satırlar
awk '{toplam += $2} END {print toplam}' v.txt   # 2. sütunun toplamı
awk 'NR>1' dosya.csv                      # başlık satırını atla

Betik yazmaya giriş

Betik, komutların bir dosyaya yazılmış hâlidir. İlk satır (shebang) hangi yorumlayıcının kullanılacağını belirtir.

#!/bin/bash
# yedekle.sh - ev dizinindeki belgeleri yedekler

KAYNAK="$HOME/belgeler"
HEDEF="$HOME/yedekler"
TARIH=$(date +%Y-%m-%d)

mkdir -p "$HEDEF"
tar -czf "$HEDEF/belgeler-$TARIH.tar.gz" "$KAYNAK"
echo "Yedek tamamlandı: belgeler-$TARIH.tar.gz"
chmod +x yedekle.sh
./yedekle.sh

Değişken, parametre ve girdi

#!/bin/bash
ad="Ayşe"                  # atama: eşittirin iki yanında boşluk olmaz
echo "Merhaba, $ad"
simdi=$(date +%H:%M)       # komut çıktısını değişkene al
echo "Saat: $simdi"

echo "Betik adı: $0"
echo "İlk parametre: $1"
echo "Parametre sayısı: $#"
echo "Hepsi: $@"

read -p "Adınız nedir? " isim
echo "Hoş geldin, $isim"

Koşullar

#!/bin/bash
if [ -f "$1" ]; then
    echo "$1 bir dosya"
elif [ -d "$1" ]; then
    echo "$1 bir dizin"
else
    echo "$1 bulunamadı"
    exit 1
fi

Döngüler

# for döngüsü
for dosya in *.txt; do
    echo "İşleniyor: $dosya"
done

for i in {1..5}; do echo "Sayı: $i"; done

# while döngüsü: dosyayı satır satır oku
while read -r satir; do
    echo "Satır: $satir"
done < liste.txt

# sayaç
n=1
while [ $n -le 3 ]; do
    echo $n
    n=$((n+1))
done

Fonksiyonlar ve hata denetimi

#!/bin/bash
set -euo pipefail          # hata olursa dur, tanımsız değişkeni hata say

log() {
    echo "[$(date +%T)] $1"
}

topla() {
    echo $(( $1 + $2 ))
}

log "Başlıyor"
sonuc=$(topla 4 5)
log "Sonuç: $sonuc"

command -v rsync >/dev/null || { echo "rsync kurulu değil"; exit 1; }

Betik yazarken iyi uygulamalar

  • Değişkenleri her zaman tırnak içinde kullanın: "$dosya" (boşluklu adlarda hatayı önler).
  • Betiğin başına #!/bin/bash ve gerekirse set -euo pipefail ekleyin.
  • Silme komutlarını çalıştırmadan önce echo ile ekrana yazdırarak deneyin.
  • Betikleri shellcheck betik.sh ile denetleyin (paket yöneticisinden kurulur).
  • Hata ayıklamak için bash -x betik.sh her adımı gösterir.
  • Sıkça kullanılan betikleri ~/bin dizinine koyup PATH’e ekleyin.

Özet

  • Boru (|) ve yönlendirme küçük komutları birleştirir.
  • grep arar, sed değiştirir, awk sütunları işler.
  • Betikler #!/bin/bash ile başlar, chmod +x ile çalıştırılır.
  • Değişken, koşul, döngü ve fonksiyon otomasyonun temelidir.

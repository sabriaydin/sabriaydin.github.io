Tarayıcı, her HTML öğesini dikdörtgen bir kutu olarak çizer. Boşlukları ve boyutları doğru ayarlamak için bu kutunun katmanlarını bilmek gerekir.

Kutu modeli

Her kutu içten dışa doğru dört katmandan oluşur:

KatmanÖzellikAçıklama
İçerikwidth, heightMetnin veya görselin bulunduğu alan
İç boşlukpaddingİçerik ile kenarlık arasındaki boşluk (arka plan rengi burayı da kaplar)
KenarlıkborderKutunun çerçevesi
Dış boşlukmarginKutunun dışındaki, komşu öğelerle arasındaki boşluk (saydamdır)
 
.kutu {
  width: 300px;
  padding: 20px;
  border: 2px solid #333;
  margin: 16px;
}

Kısa yazımda değerler saat yönündedir: padding: 10px 20px 10px 20px sırasıyla üst, sağ, alt ve sol anlamına gelir. İki değer (10px 20px) üst-alt ve sağ-solu, tek değer ise dört kenarı belirler. Tek yön için padding-top, margin-left gibi özellikler de vardır.

box-sizing: border-box

Varsayılan olarak width, yalnızca içerik alanının genişliğidir. Yukarıdaki kutunun gerçek genişliği 300 + 20 + 20 + 2 + 2 = 344px olur. Bu hesap karışıklığına yol açtığı için çoğu projede şu kural en başa yazılır:

*, *::before, *::after {
  box-sizing: border-box;
}

border-box ile width, iç boşluk ve kenarlık dahil toplam genişliği belirtir; kutu 300px olarak kalır.

Dış boşluk ile ilgili dikkat edilecekler

  • Dikey dış boşluklar birleşir. Alt alta iki öğeden üsttekinin margin-bottom: 30px, alttakinin margin-top: 20px değeri varsa aralarındaki boşluk 50px değil, 30px (büyük olan) olur.
  • margin: 0 auto ile genişliği belirli bir blok öğe yatayda ortalanır.
  • Negatif dış boşluk verilebilir; ancak öğelerin üst üste binmesine yol açabileceği için dikkatli kullanılmalıdır.
.sayfa {
  max-width: 1000px;
  margin: 0 auto;
  padding: 0 1rem;
}

display özelliği

DeğerDavranış
blockSatırın tamamını kaplar, alt satıra geçer. width, height, margin uygulanır. (div, p, h1, ul varsayılan olarak böyledir.)
inlineMetin içinde akar; width ve height uygulanmaz, dikey margin etki etmez. (span, a, strong varsayılan olarak böyledir.)
inline-blockSatır içinde akar ancak width, height ve margin uygulanır. Düğmeler için uygundur.
noneÖğe sayfada hiç yer kaplamaz (gizlenir).
flex, gridYerleşim düzenleri. Sonraki yazılarda anlatılır.

Kenar süsleri

.kart {
  border-radius: 12px;                 /* yuvarlak köşe */
  box-shadow: 0 4px 12px rgb(0 0 0 / 20%);
  overflow: hidden;                     /* taşan içeriği keser */
}

position özelliği

position, bir öğenin normal akıştan çıkıp başka bir yere yerleştirilmesini sağlar. top, right, bottom, left özellikleri konumu belirler.

DeğerDavranış
staticVarsayılan. Normal akışta kalır; top ve left etkisizdir.
relativeNormal yerine göre kaydırılır; kapladığı alan korunur. Çoğunlukla absolute çocukları için referans olarak kullanılır.
absoluteNormal akıştan çıkar. Konumlandırılmış (static olmayan) en yakın üst öğeye göre yerleşir.
fixedTarayıcı penceresine göre sabitlenir; kaydırınca yerinde kalır (sabit üst menü, "yukarı çık" düğmesi).
stickyKaydırma belirli bir noktaya ulaşana kadar normal akışta, sonra yapışık kalır.
 
.kart { position: relative; }
.etiket {
  position: absolute;
  top: 8px;
  right: 8px;
}
.ust-menu {
  position: sticky;
  top: 0;
  z-index: 10;
}

Üst üste binen öğelerde hangisinin önde görüneceğini z-index belirler; değeri yüksek olan öne çıkar. z-index yalnızca konumlandırılmış öğelerde etkilidir.

Özet

  • Kutu: içerik + padding + border + margin.
  • Boyut hesabını kolaylaştırmak için box-sizing: border-box kullanılır.
  • Dikey margin değerleri birleşir.
  • position: relative ve absolute birlikte; fixed ve sticky ise sabit öğeler için kullanılır.

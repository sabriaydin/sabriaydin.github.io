İçeriğe geç

Batch'te sayısal işlemler set /a komutuyla yapılır. Bu komutun yalnızca tamsayılarla çalıştığı ve bazı beklenmedik davranışları (sekizlik sayılar, taşma) bulunduğu bilinmelidir. Değişken tanımlama temelleri için Değişkenler ve set Komutu yazısına bakılabilir.

set /a ile işlem yapma

@echo off
set /a TOPLAM=10+5
set /a FARK=10-3
set /a CARPIM=4*6
set /a BOLUM=17/5
set /a KALAN=17%%5
echo %TOPLAM% %FARK% %CARPIM% %BOLUM% %KALAN%
pause

Bu örnekte 17/5 işleminin sonucu 3'tür; ondalık kısım atılır. Mod (kalan) işleci betik dosyalarında %%, doğrudan komut satırında % olarak yazılır. set /a içinde değişken adları % işaretleri olmadan kullanılabilir:

set /a A=8
set /a B=3
set /a C=A*B+2
echo %C%

&, |, ^, < ve > içeren ifadeler tırnak içine alınmalıdır: set /a "X=6&3". Aksi halde komut yorumlayıcısı bu karakterleri kendi işleci sanır.

Sayaç artırma ve döngüler

@echo off
set /a SAYAC=0
:dongu
set /a SAYAC+=1
echo Tur: %SAYAC%
if %SAYAC% LSS 5 goto :dongu
echo Bitti.
pause

Parantezli bloklar (for, if) içinde değişken değerinin güncel görünmesi için gecikmeli genişletme gerekir (bkz. İleri Seviye).

Sınırlar: 32 bit tamsayı

  • set /a işlemleri 32 bit işaretli tamsayı ile yapılır: -2147483648 ile 2147483647 arası.
  • Sınır aşıldığında hata verilmez, sonuç sessizce taşar: set /a X=2147483647+1 sonucu -2147483648 olur.
  • Büyük sayılar (dosya boyutları gibi) için bayt yerine MB veya GB cinsine çevirme ya da PowerShell kullanma gerekir.
rem Bayt'i MB'a cevir (taşmadan once bol)
set /a MB=BAYT/1048576

Sekizlik sayı tuzağı

Başında 0 bulunan sayılar set /a içinde sekizlik (octal) kabul edilir. 08 ve 09 geçersiz rakamlar içerdiği için hata verir. Bu durum özellikle %time% veya %date% içindeki saat ve dakika değerleri sayı olarak kullanıldığında sorun çıkarır:

set "DAKIKA=08"
set /a TOPLAM=DAKIKA+5            rem HATA: gecersiz sayi
set /a TOPLAM=1%DAKIKA% %% 100 + 5 rem DOGRU: 108 mod 100 = 8, sonuc 13

Çözümde sayının önüne 1 eklenerek 108 elde edilir, %% 100 ile baştaki 1 atılır. 0x ile başlayan sayılar onaltılık kabul edilir: set /a X=0xFF sonucu 255'tir.

Ondalık sayılar

set /a ondalık sayıyı desteklemez. İki çözüm vardır:

1. Sayıyı 100 ile çarpıp metin olarak ayırmak

@echo off
rem 7 / 4 = 1.75
set /a SONUC=7*100/4
set "TAM=%SONUC:~0,-2%"
set "KESIR=%SONUC:~-2%"
echo %TAM%,%KESIR%
pause

Bu yöntemde sonucun en az üç basamaklı (100 veya üzeri) olması gerekir; daha küçük değerler için baştan sıfır eklemek gerekir. Örnekte 175 sonucu 1,75 olarak yazılır.

2. PowerShell kullanmak

for /f %%s in ('powershell -NoProfile -Command "[math]::Round(7/4,2)"') do set "SONUC=%%s"
echo %SONUC%

Bu yöntem her türlü ondalık işlemi destekler; ancak çalışması birkaç yüz milisaniye sürer.

Yüzde ve yuvarlama

@echo off
set /a TOPLAM=250
set /a PARCA=65
set /a YUZDE=PARCA*100/TOPLAM
echo %PARCA% / %TOPLAM% = %%%YUZDE%

rem Yuvarlayarak bolme: (a + b/2) / b
set /a ORTALAMA=(17+5/2)/5
echo %ORTALAMA%
pause

Çarpma işlemi bölmeden önce yapılmalıdır; çünkü tamsayı bölmede küçük sonuçlar sıfıra yuvarlanır (65/250*100 sonucu 0 olurdu).

Rastgele sayı: %random%

%RANDOM% değişkeni her okunduğunda 0 ile 32767 arasında rastgele bir tamsayı verir. İstenen aralığa kalan işlemiyle uyarlanır:

@echo off
rem 1-6 arasi (zar)
set /a ZAR=%RANDOM% %% 6 + 1
echo Zar: %ZAR%

rem 1-100 arasi
set /a SAYI=%RANDOM% %% 100 + 1
echo Sayi: %SAYI%

rem 50-60 arasi (50 + 0..10)
set /a ARALIK=%RANDOM% %% 11 + 50
echo %ARALIK%
pause

Genel kural: %RANDOM% %% (en_büyük - en_küçük + 1) + en_küçük.

%RANDOM% güvenlik amaçlı (parola, anahtar) kullanılmamalıdır; tahmin edilebilir bir üreteçtir. Parola üretmek için Güçlü Parola Üretici aracı kullanılabilir.

Örnek: basit hesap makinesi

@echo off
set /p SAYI1=Birinci sayi: 
set /p SAYI2=Ikinci sayi: 
set /a TOPLAM=SAYI1+SAYI2
set /a CARPIM=SAYI1*SAYI2
echo Toplam: %TOPLAM%
echo Carpim: %CARPIM%
if %SAYI2% NEQ 0 (
    set /a BOLUM=SAYI1/SAYI2
    set /a KALAN=SAYI1%%SAYI2
    echo Bolum: %BOLUM% Kalan: %KALAN%
)
pause

Özet

  • set /a yalnızca tamsayı ile, 32 bit sınırları içinde çalışır; bölme sonucu küçülür.
  • %% betikte mod işlecidir. Bit işleçleri içeren ifadeler tırnak içine alınır.
  • Başında sıfır olan sayılar sekizlik sayılır; 08 ve 09 hata verir.
  • Ondalık işlemler için sayı çarpılarak ayrılır veya PowerShell kullanılır.
  • %RANDOM% %% n ile 0 ile n-1 arasında sayı üretilir.

İçeriğe geç

HTML sayfanın yapısını, CSS (Cascading Style Sheets) ise görünüşünü belirler: renkler, yazı tipleri, boşluklar, yerleşim. Bu derste CSS'in temelini öğrenip sayfanı güzelleştireceksin.

CSS nasıl yazılır?

Her CSS kuralı bir seçici ve süslü parantez içinde özellik: değer; çiftlerinden oluşur:

h1 {
  color: darkred;
  text-align: center;
}

Bu kural "bütün <h1> başlıklarını koyu kırmızı yap ve ortala" demektir.

CSS'i sayfaya bağlamanın 3 yolu

YolNasılNe zaman
Satır içi<p style="color: red;">Tek bir öğeye hızlı ayar
<style> etiketi<head> içine yazılırTek sayfalık denemeler
Dış dosya<link rel="stylesheet" href="style.css">Asıl yöntem; tüm sayfalar aynı dosyayı kullanır
 
<head>
  <meta charset="utf-8">
  <title>Stilli sayfa</title>
  <link rel="stylesheet" href="style.css">
</head>

Dış dosya için index.html yanına style.css adında bir metin dosyası oluştur ve CSS kurallarını oraya yaz.

Kutu modeli

Tarayıcı her HTML öğesini bir kutu olarak görür. Kutu, içten dışa şu katmanlardan oluşur:

  • İçerik (content): yazı veya resim
  • İç boşluk (padding): içerik ile kenarlık arası
  • Kenarlık (border)
  • Dış boşluk (margin): kutu ile komşu kutular arası
* { box-sizing: border-box; }

.kart {
  width: 300px;
  padding: 16px;
  border: 1px solid #ccc;
  margin: 20px auto;
}

box-sizing: border-box yazılırsa belirlediğin width kenarlık ve iç boşluk dahil olur; hesap kolaylaşır. Neredeyse her projede en başa yazılır. margin: 20px auto ise kutuyu yatayda ortalar.

Birimler

  • px: piksel; sabit boyut.
  • %: kapsayıcıya oranla.
  • rem: sayfanın temel yazı boyutuna oranla (1rem genelde 16 piksel). Yazı boyutları için esnek ve önerilen birimdir.

Uygulama

Aşağıdaki kodu HTML Önizleme aracına yapıştır, renkleri ve boşlukları değiştirerek sonucu izle:

<!DOCTYPE html>
<html lang="tr">
<head>
  <meta charset="utf-8">
  <title>CSS denemesi</title>
  <style>
    * { box-sizing: border-box; }
    body {
      font-family: Arial, sans-serif;
      background-color: #f1eee9;
      color: #222;
      margin: 0;
      padding: 20px;
    }
    h1 { color: #b72a25; text-align: center; }
    .kart {
      max-width: 400px;
      margin: 20px auto;
      padding: 20px;
      background-color: #faf8f5;
      border: 1px solid #ccc;
      border-radius: 10px;
    }
    a { color: #b72a25; }
    a:hover { color: #6e1a17; }
  </style>
</head>
<body>
  <h1>Merhaba CSS!</h1>
  <div class="kart">
    <h2>İlk kartım</h2>
    <p>CSS ile sayfayı istediğin gibi şekillendirebilirsin.</p>
    <a href="#">Devamını oku</a>
  </div>
</body>
</html>

Sonraki derste şimdiye kadar öğrendiğin her şeyi birleştirip eksiksiz bir kişisel tanıtım sayfası yapacak ve yayınlayacaksın.

İçeriğe geç

Kayıt defteri (Registry), Windows ve uygulamaların ayarlarını sakladığı hiyerarşik veri tabanıdır. Batch betikleri reg komutuyla bu veri tabanını okuyabilir ve değiştirebilir. Yanlış bir değişiklik sistemin veya programların çalışmasını bozabileceğinden her değişiklikten önce yedek alınmalıdır.

Yapı

KısaltmaTam adİçerik
HKCUHKEY_CURRENT_USERGeçerli kullanıcının ayarları
HKLMHKEY_LOCAL_MACHINEBilgisayarın tüm kullanıcılar için ayarları (değişiklik için yönetici gerekir)
HKCRHKEY_CLASSES_ROOTDosya türü ilişkilendirmeleri
HKUHKEY_USERSTüm kullanıcı profilleri

Anahtarlar klasör, değerler ise bu anahtarların içindeki adlı verilerdir. Değer türleri: REG_SZ (metin), REG_DWORD (32 bit sayı), REG_QWORD (64 bit sayı), REG_MULTI_SZ (metin listesi), REG_EXPAND_SZ (değişken içeren metin), REG_BINARY (ikili veri).

Okuma: reg query

reg query "HKCU\Control Panel\Desktop"
reg query "HKCU\Control Panel\Desktop" /v WallPaper
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion" /v ProductName
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run"
reg query "HKCU\Software" /f "Sample" /s       rem alt anahtarlarda arama

Bir değerin batch değişkenine alınması:

@echo off
for /f "tokens=2,*" %%a in ('reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion" /v ProductName 2^>nul ^| find "ProductName"') do set "SURUM=%%b"
echo Windows surumu: %SURUM%
pause
  • Çıktı satırı ProductName REG_SZ Windows 11 Pro biçimindedir; tokens=2,* ikinci parçadan sonrasını (%%b) alır.
  • 2^>nul ifadesindeki ^, for içindeki komutta yönlendirme işaretinden kaçmak içindir.

Yazma: reg add

rem metin degeri
reg add "HKCU\Software\Denemem" /v Ad /t REG_SZ /d "Merhaba" /f

rem sayi degeri
reg add "HKCU\Software\Denemem" /v Deger /t REG_DWORD /d 1 /f

rem varsayilan deger
reg add "HKCU\Software\Denemem" /ve /d "varsayilan" /f
SeçenekAnlamı
/v adDeğer adı
/t türDeğer türü
/d veriDeğerin verisi
/fOnay sormadan üzerine yazar
/reg:64 / /reg:3264 veya 32 bit kayıt defteri görünümünü seçer

Silme: reg delete

reg delete "HKCU\Software\Denemem" /v Ad /f      rem yalnizca bir deger
reg delete "HKCU\Software\Denemem" /f             rem anahtar ve icindeki her sey
Anahtar silme işlemi geri alınamaz. Silmeden önce yedek alınmalı, yol dikkatle denetlenmelidir. Yalnızca HKCU\Software\Denemem gibi kendi oluşturulan anahtarlarla deneme yapılması önerilir.

Yedekleme ve geri yükleme

rem yedek al
reg export "HKCU\Software\Denemem" "%USERPROFILE%\Desktop\denemem_yedek.reg" /y

rem geri yukle
reg import "%USERPROFILE%\Desktop\denemem_yedek.reg"

rem tum anahtari dosyaya kaydet/yukle (hive)
reg save "HKCU\Software\Denemem" yedek.hiv
reg restore "HKCU\Software\Denemem" yedek.hiv

.reg dosyası düz metindir ve Not Defteri ile incelenebilir. /y önceki dosyanın üzerine yazmayı onaylar.

Uygulamalı örnekler

Başlangıçta çalışan programları listeleme

@echo off
echo --- Kullanici baslangic programlari ---
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run"
echo.
echo --- Sistem baslangic programlari ---
reg query "HKLM\Software\Microsoft\Windows\CurrentVersion\Run"
pause

Dosya uzantılarını görünür yapma

@echo off
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v HideFileExt /t REG_DWORD /d 0 /f
echo Degisiklik, Gezgin yeniden baslatildiginda gorunur.
taskkill /f /im explorer.exe > nul
start explorer.exe

Bu örnek HideFileExt değerini 0 yaparak bilinen dosya uzantılarının gösterilmesini sağlar. Gezgin'in yeniden başlatılması masaüstünün birkaç saniye kaybolmasına neden olur.

Güvenlik uyarıları

  • Bilinmeyen kaynaklardan alınan .reg dosyaları çift tıklanıp içe aktarılmamalıdır; sistem ayarlarını ve başlangıç girdilerini değiştirebilir.
  • HKLM altındaki değişiklikler yönetici yetkisi gerektirir ve tüm kullanıcıları etkiler.
  • Değişiklik öncesinde reg export ile yedek, mümkünse sistem geri yükleme noktası oluşturulmalıdır.
  • Kötü amaçlı yazılımlar Run anahtarlarına kendini ekleyerek kalıcılık sağlar; bu anahtarların düzenli denetimi güvenlik açısından yararlıdır.

Özet

  • reg query okur, reg add yazar, reg delete siler, reg export ve reg import yedekler ve geri yükler.
  • Yol boşluk içerdiğinde tırnak kullanılır; HKLM değişiklikleri yönetici ister.
  • Her değişiklikten önce yedek alınır.

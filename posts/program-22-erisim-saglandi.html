Bip sesiyle birlikte büyük harflerle ERİŞİM SAĞLANDI yazan, bir işlemin sonunda kullanılabilecek sahte final ekranı.

İçindekiler
  1. Nasıl kullanılır?
  2. Kod nasıl çalışıyor?
  3. Özelleştirme

Bu program, önceki örneklerle birlikte kullanılabilecek kısa bir "final" ekranıdır: ekran yeşile döner, bip sesi çalar ve büyük bir başarı mesajı gösterir.

Önemli: Bu program tamamen görsel bir gösteridir; hiçbir dosyayı silmez, hiçbir ayarı değiştirmez ve internete bağlanmaz. Yalnızca ekran yazısını, rengini ve bir pencere başlığını değiştirir; pencereyi kapattığınızda bilgisayarınızda hiçbir iz kalmaz. Şaka amaçlı kullanırken karşındaki kişiyi gerçekten korkutmamaya dikkat et.

Nasıl kullanılır?

  1. Aşağıdaki kodu Not Defteri'ne yapıştırın ve program-22-erisim-saglandi.bat adıyla kaydedin (Kayıt türü: Tüm dosyalar).
  2. Çift tıklayarak çalıştırın. Kapatmak için pencereyi normal şekilde kapatın veya Ctrl+C kullanın.
@echo off
title Tamamlandi
color 0a
cls
echo.
echo.
echo        #####  #####  #  ####  # #   #
echo        #    # #    # # #      # ##  #
echo        #    # #    # #  ####  # # # #
echo        #####  #####  #      # # #  ##
echo        #      #   #  # #    # # #   #
echo        #      #    # #  ####  # #   #
echo.
echo             ERISIM SAGLANDI
echo.
echo.
pause >nul

Kod nasıl çalışıyor?

En son satırdaki echo.'nun ardından, konsolda bir "bip" sesi çıkarmak için kullanılan özel karakter (ASCII 7, BEL) yerleştirilmiştir; Not Defteri'nde bu karakter doğrudan görünmez, yalnızca program çalıştığında bip sesi olarak duyulur. Bip sesi istemiyorsanız o satırı silebilirsiniz; program görsel olarak aynı şekilde çalışmaya devam eder.

Özelleştirme

Kodun başındaki AYARLAR bölümündeki (varsa) değerleri değiştirerek metni, rengi veya hızı kendinize göre ayarlayabilirsiniz. color 0a komutundaki ilk rakam zemin, ikinci rakam yazı rengidir (0: siyah, a: açık yeşil, b: açık camgöbeği, c: açık kırmızı, e: sarı, f: beyaz).

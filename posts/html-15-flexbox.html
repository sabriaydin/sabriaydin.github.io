Flexbox, öğeleri tek bir sıra (yatay veya dikey) üzerinde düzenlemek için tasarlanmış yerleşim yöntemidir. Menüler, kart sıraları, ortalama ve eşit aralıklı dizme işlerinde yaygın olarak kullanılır.

Temel mantık

Bir öğeye display: flex verildiğinde o öğe flex kapsayıcı, doğrudan çocukları ise flex öğeleri olur.

<div class="sira">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>

.sira {
  display: flex;
}

Çocuklar artık alt alta değil, yan yana dizilir. İki eksen vardır: ana eksen (öğelerin dizildiği yön, varsayılan yatay) ve çapraz eksen (ana eksene dik yön).

Kapsayıcı özellikleri

ÖzellikDeğerlerEtkisi
flex-directionrow (varsayılan), column, row-reverse, column-reverseAna ekseni belirler. column ile öğeler alt alta dizilir.
justify-contentflex-start, center, flex-end, space-between, space-around, space-evenlyÖğeleri ana eksen boyunca hizalar.
align-itemsstretch (varsayılan), flex-start, center, flex-end, baselineÖğeleri çapraz eksen boyunca hizalar.
flex-wrapnowrap (varsayılan), wrapSığmayan öğelerin alt satıra geçmesini sağlar.
gap16px, 1rem 2remÖğeler arasında boşluk bırakır (margin gerekmez).

Sık kullanılan örnekler

Yatay menü

nav ul {
  display: flex;
  gap: 1.5rem;
  list-style: none;
  padding: 0;
}

Bir öğeyi tam ortalama

.orta {
  display: flex;
  justify-content: center;  /* yatayda */
  align-items: center;      /* dikeyde */
  min-height: 100vh;
}

Logo solda, bağlantılar sağda

header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Öğe özellikleri

ÖzellikEtkisi
flex-growBoş alan varsa öğenin ne kadar büyüyeceğini belirler (sayı, oran olarak).
flex-shrinkAlan yetersizse öğenin küçülme oranı. 0 yazılırsa küçülmez.
flex-basisBüyüme veya küçülme öncesindeki başlangıç boyutu.
flexÜçünün kısa yazımı: flex: 1 boş alanı eşit paylaşmayı sağlar.
align-selfTek bir öğenin çapraz eksen hizalamasını değiştirir.
orderÖğelerin görsel sırasını değiştirir (HTML sırası aynı kalır).
 
.yan-panel { width: 240px; }
.icerik    { flex: 1; }          /* kalan alanı doldurur */

Kart sırası örneği

.kartlar {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.kart {
  flex: 1 1 250px;   /* büyüyebilir, küçülebilir, en az ~250px */
}

Bu yapıda pencere daraldıkça kartlar otomatik olarak alt satıra geçer; ayrıca bir @media kuralı gerekmez.

justify-content ve align-items değerleri flex-direction: column olduğunda ters çalışır: ana eksen dikey olduğu için justify-content dikey hizalamayı belirler.

Özet

  • Kapsayıcıya display: flex verilir; çocuklar flex öğesi olur.
  • Ana eksen için justify-content, çapraz eksen için align-items kullanılır.
  • gap ile aralık, flex-wrap ile satıra geçiş, flex: 1 ile alan paylaşımı sağlanır.
  • Flexbox tek boyutlu (satır veya sütun) düzenler içindir; satır ve sütunu birlikte yönetmek için Grid kullanılır.

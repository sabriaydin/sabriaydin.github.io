CSS Grid, öğeleri hem satır hem sütun yönünde düzenleyen iki boyutlu yerleşim sistemidir. Kart galerileri, sayfa şablonları ve panel düzenleri için uygundur.

Temel kullanım

<div class="izgara">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
</div>

.izgara {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 1rem;
}

grid-template-columns sütunları tanımlar. Yukarıdaki örnekte eşit genişlikte üç sütun oluşur ve öğeler satır satır otomatik yerleşir. gap, hem satır hem sütun aralığını belirler (ayrı ayrı row-gap ve column-gap de yazılabilir).

fr birimi ve repeat()

  • fr (fraction), kalan alanın payını gösterir: 1fr 2fr yazılırsa ikinci sütun birinciden iki kat geniş olur.
  • px, %, rem ile fr birlikte kullanılabilir: 240px 1fr sabit bir yan panel ve esnek bir içerik alanı oluşturur.
  • repeat(3, 1fr), 1fr 1fr 1fr ifadesinin kısa yazımıdır.
.a { grid-template-columns: repeat(3, 1fr); }
.b { grid-template-columns: 240px 1fr; }
.c { grid-template-columns: 2fr 1fr; }

Satır yükseklikleri

Satırlar içeriğe göre otomatik yükselir. Sabit bir yükseklik gerekirse grid-auto-rows veya grid-template-rows kullanılır:

.izgara {
  grid-auto-rows: minmax(120px, auto);  /* en az 120px, içerik büyükse uzar */
}

Duyarlı kart ızgarası: auto-fit ve minmax()

Aşağıdaki tek satır, ekran genişliğine göre sütun sayısını kendisi belirler. Kartlar en az 220px genişliğinde olur; yer varsa sütun sayısı artar, yer yoksa azalır.

.kartlar {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

Öğeleri birden fazla hücreye yayma

.genis  { grid-column: span 2; }   /* 2 sütun kaplar */
.uzun   { grid-row: span 2; }      /* 2 satır kaplar */
.tam    { grid-column: 1 / -1; }   /* ilk çizgiden son çizgiye: tüm genişlik */

Izgara çizgiler üzerine kuruludur: 3 sütunlu bir ızgarada 4 dikey çizgi vardır (1, 2, 3, 4). -1 son çizgiyi belirtir.

grid-template-areas ile sayfa şablonu

Alanlara ad verilerek sayfa düzeni görsel olarak yazılabilir:

.sayfa {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-areas:
    "ust   ust"
    "yan   icerik"
    "alt   alt";
  gap: 1rem;
}
header { grid-area: ust; }
aside  { grid-area: yan; }
main   { grid-area: icerik; }
footer { grid-area: alt; }

Dar ekranda tek sütuna geçmek için @media içinde yalnızca grid-template-areas ve grid-template-columns değerleri değiştirilir (bkz. Duyarlı Tasarım).

Hizalama

ÖzellikEtkisi
justify-items, align-itemsÖğeleri kendi hücreleri içinde yatay ve dikey hizalar.
justify-content, align-contentTüm ızgarayı kapsayıcı içinde hizalar (ızgara kapsayıcıdan küçükse).
place-items: centerİki hizalamayı birlikte, öğeleri hücre ortasına yerleştirir.

Flexbox mu, Grid mi?

DurumUygun yöntem
Tek sıra: menü, düğme grubu, ortalamaFlexbox
Satır ve sütunları birlikte yönetme: galeri, sayfa şablonu, panelGrid
İçeriğin boyutuna göre düzen kurmaFlexbox
Önce düzeni tasarlayıp içeriği sonra yerleştirmeGrid

İkisi birlikte de kullanılabilir: sayfa iskeleti Grid ile kurulur, her bölümün içindeki öğeler Flexbox ile dizilir.

Özet

  • display: grid ve grid-template-columns ile ızgara kurulur.
  • fr kalan alanı paylaştırır; repeat() tekrarı kısaltır.
  • repeat(auto-fit, minmax(220px, 1fr)) duyarlı kart ızgarası için yeterlidir.
  • span, grid-column ve grid-area ile öğeler birden fazla hücreye yayılabilir.

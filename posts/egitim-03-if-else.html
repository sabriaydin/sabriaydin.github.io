Batch Rehberi

if ile metin, sayı, dosya ve hata kodu karşılaştırmaları; else yazımı ve sık yapılan parantez hataları.

İçindekiler
  1. Metin karşılaştırma
  2. if ve else
  3. Sayı karşılaştırma operatörleri
  4. Dosya ve klasör kontrolü
  5. Değişken tanımlı mı?
  6. Hata kodu kontrolü
  7. Birden fazla koşul

if komutu bir şart doğruysa komut çalıştırır. Menüler, dosya kontrolleri ve hata yönetimi hep if ile kurulur.

Metin karşılaştırma

@echo off
set /p "cevap=Devam edilsin mi? (e/h): "
if "%cevap%"=="e" echo Devam ediliyor...
if "%cevap%"=="h" echo Iptal edildi.
pause

Değişkeni çift tırnak içine almak önemlidir. Kullanıcı hiçbir şey yazmazsa tırnaksız if %cevap%==e satırı if ==e olur ve hata verir. Büyük/küçük harf farkını yok saymak için /i ekle:

if /i "%cevap%"=="E" echo Evet

if ve else

else, if bloğunun kapanış parantezinin aynı satırında olmalıdır:

@echo off
set /p "yas=Yasin kac? "
if %yas% geq 18 (
    echo Yetiskinsin.
) else (
    echo Henuz 18 yasindan kucuksun.
)
pause

Aşağıdaki yazım hata verir, çünkü else alt satıra düşmüştür:

if %yas% geq 18 (
    echo Yetiskinsin.
)
else (
    echo Kucuksun.
)

Sayı karşılaştırma operatörleri

Sayılarda == yerine aşağıdaki kısaltmaları kullanırsan değerler sayı olarak karşılaştırılır. == ise metin karşılaştırır; metin olarak "10", "9"dan küçüktür.

OperatörAnlamı
equeşit
neqeşit değil
lssküçük
leqküçük veya eşit
gtrbüyük
geqbüyük veya eşit

Dosya ve klasör kontrolü

@echo off
if exist "C:\Yedek" (
    echo Yedek klasoru var.
) else (
    echo Yedek klasoru yok, olusturuluyor...
    md "C:\Yedek"
)
pause

Tersi için if not exist yazılır. Yolun sonuna ters bölü ekleyerek ("C:\Yedek\") yalnızca klasör olup olmadığını kontrol edebilirsin.

Değişken tanımlı mı?

if defined ad (echo ad tanimli) else (echo ad tanimli degil)

Hata kodu kontrolü

Çalışan her komut bir çıkış kodu bırakır. 0 başarı demektir. if errorlevel 1 ifadesi, çıkış kodu 1 veya daha büyükse doğrudur. Ayrıntısı 8. derste.

@echo off
ping -n 1 google.com >nul
if errorlevel 1 (
    echo Internet yok.
) else (
    echo Internet var.
)
pause

Birden fazla koşul

Batch'te and ve or yoktur. "Ve" için if satırlarını art arda yazarsın, "veya" için bir işaret değişkeni kullanırsın:

rem VE: ikisi de dogruysa
if "%ad%"=="Sabri" if "%sehir%"=="Izmir" echo Ikisi de dogru

rem VEYA: biri dogruysa
set "bulundu=0"
if "%renk%"=="kirmizi" set "bulundu=1"
if "%renk%"=="mavi" set "bulundu=1"
if "%bulundu%"=="1" echo Renk kirmizi ya da mavi

Bir sonraki derste aynı işi tekrar tekrar yaptıran for döngülerine geçiyoruz.

Batch Uygulamaları

hosts dosyasındaki yönlendirmeleri, DNS sunucularını ve proxy ayarlarını denetleyerek trafik yönlendirme saldırılarının izlerini arayan batch uygulaması.

Bazı kötü amaçlı yazılımlar, bir sitenin adresini sahte siteye yönlendirmek için hosts dosyasını, DNS sunucusu ayarını veya proxy ayarını değiştirir. Bu durumda tarayıcı doğru adresi gösterirken kullanıcı farkında olmadan sahte bir sayfaya ulaşabilir. Bu uygulama, üç ayarı kontrol eder ve alışılmadık olanları işaretler.

Ne yapar?

  • Hosts dosyası: hosts dosyasındaki yorum olmayan satırları listeler. 127.0.0.1 ve 0.0.0.0 adreslerine yönlendirenleri engelleme/yerel giriş, diğerlerini yönlendirme olarak işaretler. Dosyanın son değişiklik tarihini gösterir.
  • DNS sunucuları: Bağdaştırıcıların kullandığı DNS adreslerini listeler; bilinen genel DNS sağlayıcıları (Cloudflare, Google, Quad9, OpenDNS) ve yerel ağ adresleri dışındakileri tanınmayan olarak işaretler.
  • Proxy ayarları: Sistem proxy'sinin ve otomatik proxy betiğinin (PAC) tanımlı olup olmadığını, ayrıca WinHTTP proxy ayarını gösterir.
  • İstenirse DNS önbelleğini temizler.

Nasıl kullanılır?

  1. Kod Not Defteri'ne yapıştırılır ve dns_kalkani.bat adıyla kaydedilir (Kayıt türü: Tüm dosyalar seçilmelidir; aksi halde dosya .txt olarak kaydedilir).
  2. Dosyaya çift tıklanarak çalıştırılır.
  3. Betik yönetici yetkisi gerektirmez. Sonunda DNS önbelleğinin temizlenip temizlenmeyeceği sorulur (E veya H).
@echo off
setlocal EnableExtensions
title [ DNS SHIELD ] Hosts, DNS ve Proxy Butunluk Denetimi
color 0A
cls
echo.
echo   ====================================================
echo    [ DNS SHIELD ]  Hosts, DNS ve Proxy Denetimi
echo   ====================================================
echo.
set /a UYARI=0

echo [*] 1/4 Hosts dosyasi
echo.
set "HOSTS=%SystemRoot%\System32\drivers\etc\hosts"
for %%f in ("%HOSTS%") do echo     Son degisiklik: %%~tf
set /a GIRIS=0
for /f "usebackq eol=# tokens=1,2" %%a in ("%HOSTS%") do call :hostsatir %%a %%b
if %GIRIS% EQU 0 echo [+] Ozel giris yok ^(hosts dosyasi varsayilan durumda^).
echo.

echo [*] 2/4 DNS sunuculari
echo.
powershell -NoProfile -Command "$k='1.1.1.1','1.0.0.1','8.8.8.8','8.8.4.4','9.9.9.9','149.112.112.112','208.67.222.222','208.67.220.220'; Get-DnsClientServerAddress -AddressFamily IPv4 | ForEach-Object { foreach ($a in $_.ServerAddresses) { $d='[?] TANINMAYAN'; if ($k -contains $a) { $d='[+] bilinen saglayici' } elseif ($a -match '^(10\.|192\.168\.|172\.(1[6-9]|2[0-9]|3[01])\.|127\.)') { $d='[+] yerel ag' }; '    {0,-26} {1,-16} {2}' -f $_.InterfaceAlias,$a,$d } }"
echo.

echo [*] 3/4 Proxy ayarlari
echo.
set "IS=HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings"
call :reg PROXYAC "%IS%" ProxyEnable
call :reg PROXYSUNUCU "%IS%" ProxyServer
call :reg OTOYAPI "%IS%" AutoConfigURL
if "%PROXYAC%"=="0x1" echo [!] Sistem proxy'si ETKIN: %PROXYSUNUCU%
if "%PROXYAC%"=="0x1" set /a UYARI+=1
if not "%PROXYAC%"=="0x1" echo [+] Sistem proxy'si kapali.
if not "%OTOYAPI%"=="Bilinmiyor" echo [!] Otomatik proxy betigi tanimli: %OTOYAPI%
if not "%OTOYAPI%"=="Bilinmiyor" set /a UYARI+=1
if "%OTOYAPI%"=="Bilinmiyor" echo [+] Otomatik proxy betigi ^(PAC^) tanimli degil.
echo.
echo     WinHTTP proxy:
netsh winhttp show proxy
echo.

echo [*] 4/4 Ozet
echo.
if %UYARI% EQU 0 goto :temiz
echo [!] %UYARI% bulgu var. Taniyamadiginiz yonlendirme ve proxy
echo     kayitlarinin kaynagini arastirin; kendiniz eklemediyseniz
echo     kaldirin ve virus taramasi yapin.
goto :dns_sor
:temiz
echo [+] Belirgin bir yonlendirme veya proxy bulgusu yok.

:dns_sor
echo.
choice /c EH /n /m "DNS onbellegi temizlensin mi? [E/H]: "
if errorlevel 2 goto :bitti
ipconfig /flushdns
:bitti
echo.
pause
exit /b 0

rem ---------- Alt programlar ----------

:hostsatir
rem %1 = IP adresi, %2 = alan adi
set "A=%~1"
if "%A:~0,1%"=="#" exit /b
set /a GIRIS+=1
set "TUR=[!] YONLENDIRME"
if "%~1"=="127.0.0.1" set "TUR=[i] yerel/engelleme"
if "%~1"=="0.0.0.0" set "TUR=[i] yerel/engelleme"
if "%~1"=="::1" set "TUR=[i] yerel/engelleme"
echo     %TUR%: %~1  %~2
if "%TUR%"=="[!] YONLENDIRME" set /a UYARI+=1
exit /b

:reg
rem %1 = degisken adi, %2 = anahtar, %3 = deger adi
set "%~1=Bilinmiyor"
for /f "tokens=3" %%a in ('reg query "%~2" /v %~3 2^>nul ^| findstr /i "%~3"') do set "%~1=%%a"
exit /b

Kod nasıl çalışıyor?

  • for /f ... eol=#: hosts dosyasını satır satır okur, # ile başlayan yorum satırlarını atlar. tokens=1,2 satırdaki ilk iki parçayı (adres ve alan adı) alır, her satır :hostsatir alt programına gönderilir.
  • Düzenli ifade: PowerShell'deki -match kuralı 10., 192.168., 172.16-31. ve 127. ile başlayan adresleri yerel ağ olarak tanır.
  • Kayıt defteri: ProxyEnable değeri 0x1 ise sistem proxy'si açıktır. ProxyServer ve AutoConfigURL değerleri de aynı :reg alt programıyla okunur.
  • Sayaç: Her riskli bulgu UYARI değişkenini artırır; özet bölümü buna göre mesaj verir.

Sonuçların yorumlanması

  • Windows'un varsayılan hosts dosyası yalnızca yorum içerir. Kendiniz eklemediğiniz bir satır varsa şüphelidir; özellikle banka, e-posta veya arama motoru adlarının başka bir adrese yönlendirilmesi ciddi bir işarettir.
  • Tanınmayan DNS sunucusu otomatik olarak kötü niyetli değildir (internet sağlayıcıları kendi sunucularını kullanır), ancak kurulmadığı hâlde değiştirilmişse yönlendirici ve bilgisayar ayarları kontrol edilmelidir.
  • Kullanılmadığı hâlde etkin bir proxy veya PAC adresi, trafiğin başka bir sunucudan geçirildiği anlamına gelebilir. Kurumsal ağlarda bu ayarların bulunması normaldir.
  • Bulgu tespit edildiğinde ilgili ayar kaldırılmalı, sistem virüs taramasından geçirilmeli ve önemli hesapların parolaları başka bir cihazdan değiştirilmelidir.
hosts dosyası yalnızca okunur; betik dosyada değişiklik yapmaz. Tek değişiklik, istenirse DNS önbelleğinin temizlenmesidir.

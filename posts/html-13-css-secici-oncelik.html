Seçici, bir CSS kuralının hangi öğelere uygulanacağını belirler. Doğru seçici kullanımı, kodun kısa ve bakımı kolay olmasını sağlar. Aynı öğeye birden fazla kural uygulandığında hangisinin geçerli olacağı ise özgüllük ve sıra kurallarıyla belirlenir.

Temel seçiciler

SeçiciÖrnekHedef
Etiketp { }Tüm p öğeleri
Sınıf.kart { }class="kart" olan tüm öğeler
Kimlik#ust { }id="ust" olan tek öğe (bir sayfada bir kez kullanılmalıdır)
Evrensel* { }Tüm öğeler
Gruph1, h2, h3 { }Virgülle ayrılan seçicilerin hepsi
 
<p class="uyari ozel">Dikkat</p>

.uyari { color: #b00020; }
.ozel  { font-weight: 700; }

Bir öğeye birden fazla sınıf boşlukla ayrılarak verilebilir. Biçimlendirme için çoğunlukla sınıf seçicisi tercih edilir; id seçicisi hem özgüllüğü yükselttiği hem de yeniden kullanılamadığı için stil vermede önerilmez.

İlişki seçicileri

SeçiciÖrnekAçıklama
Alt öğe (boşluk)nav a { }nav içindeki tüm a öğeleri (kaç seviye altta olursa olsun)
Doğrudan çocukul > li { }Yalnızca ul öğesinin doğrudan çocuğu olan li öğeleri
Hemen sonraki kardeşh2 + p { }h2 öğesinden hemen sonra gelen p
Sonraki tüm kardeşlerh2 ~ p { }h2 öğesinden sonra gelen aynı düzeydeki tüm p öğeleri

Nitelik seçicileri

a[target="_blank"] { color: green; }
input[type="email"] { border-color: blue; }
a[href^="https"] { }   /* https ile başlayan */
a[href$=".pdf"] { }    /* .pdf ile biten */

Sahte sınıflar ve sahte öğeler

Sahte sınıf (:) bir öğenin belirli bir durumunu hedefler. Sahte öğe (::) ise öğenin bir parçasını veya öğeye eklenen içeriği hedefler.

SeçiciNe zaman uygulanır?
a:hoverFare öğenin üzerindeyken
a:focus, input:focusÖğe klavye veya tıklamayla odaklandığında
a:visitedZiyaret edilmiş bağlantılarda
li:first-child, li:last-childİlk ve son çocuk öğe
li:nth-child(2)2. çocuk. odd ve even ile tek ve çift sıradakiler seçilir.
input:checked, input:disabledİşaretli ve devre dışı form alanları
p::first-lineParagrafın ilk satırı
::before, ::afterÖğenin önüne ve sonuna content ile içerik ekler
 
.dugme:hover { background: #8a1f1b; }
.dugme:focus-visible { outline: 3px solid #1a73e8; }
li:nth-child(even) { background: #f3f3f3; }
.not::before { content: "Not: "; font-weight: 700; }
Klavyeyle gezinenler için :focus biçimlendirmesi kaldırılmamalıdır. outline: none yazılacaksa yerine görünür başka bir odak göstergesi tanımlanmalıdır.

Özgüllük: hangi kural kazanır?

Aynı öğeyi ve aynı özelliği hedefleyen birden fazla kural varsa, tarayıcı özgüllüğü yüksek olanı uygular. Özgüllük eşitse dosyada sonra gelen kural geçerli olur.

Seçici türüAğırlık
Satır içi stil (style="...")En yüksek
Kimlik (#ust)100
Sınıf, nitelik, sahte sınıf (.kart, [type], :hover)10
Etiket, sahte öğe (p, ::before)1
 
p            { color: black; }   /* 1   */
.vurgu       { color: green; }   /* 10  */
p.vurgu      { color: blue; }    /* 11  */
#ozel        { color: red; }     /* 100 */

Yukarıdaki kuralların hepsi aynı öğeye uygulanırsa, id değeri ozel olan öğe kırmızı, yalnızca vurgu sınıfı olan p öğesi mavi görünür.

!important

Bir değerin sonuna !important eklenirse normal özgüllük hesabı geçersiz kalır. Ancak bu, kodun yönetilmesini zorlaştırır; yalnızca başka çözüm yoksa kullanılmalıdır.

Kalıtım

color, font-family, font-size ve line-height gibi bazı özellikler alt öğelere otomatik olarak geçer. border, margin ve padding gibi özellikler geçmez. Bu nedenle yazı tipi ve renk çoğunlukla body için bir kez tanımlanır.

CSS değişkenleri

Tekrar eden değerler (renk, boşluk vb.) tek bir yerde tanımlanıp var() ile kullanılabilir. Değer değiştirildiğinde tüm sayfa güncellenir.

:root {
  --ana-renk: #c0392b;
  --bosluk: 1rem;
}
.dugme {
  background: var(--ana-renk);
  padding: var(--bosluk);
}

Özet

  • Biçimlendirme için çoğunlukla sınıf seçicisi kullanılır.
  • Seçici ne kadar özgülse (kimlik > sınıf > etiket) o kadar önceliklidir; eşitlikte sonra gelen kazanır.
  • :hover, :focus ve :nth-child() gibi sahte sınıflar öğenin durumuna göre stil verir.
  • Tekrar eden değerler için CSS değişkenleri kullanılır.

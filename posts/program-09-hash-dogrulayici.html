Batch Uygulamaları

certutil ile bir dosyanın SHA256, SHA512, SHA1 veya MD5 özet değerini hesaplayıp indirme sayfasındaki değerle karşılaştıran ve sonuçları kaydeden batch uygulaması.

İndirilen bir programın, yazılımı yayımlayan kişi tarafından hazırlanan dosyayla birebir aynı olduğundan emin olmak güvenlik açısından önemlidir. Güvenilir yazılım sitelerinin çoğu, indirme bağlantısının yanında dosyanın özet (hash) değerini yayımlar. Dosya yolda bozulursa veya değiştirilirse özet değeri tamamen farklı çıkar. Bu uygulama, özet değerini hesaplar ve yayımlanan değerle karşılaştırır.

Ne yapar?

  • Sürükle-bırak veya yol yazma ile verilen dosyanın özetini hesaplar.
  • SHA256 (önerilen), SHA512, SHA1 ve MD5 algoritmalarını destekler.
  • İsteğe bağlı olarak girilen beklenen değerle karşılaştırır ve DOĞRULANDI veya UYUŞMUYOR sonucunu verir.
  • Her işlemi tarih ve saatle birlikte hash_kayitlari.txt dosyasına ekler.

Nasıl kullanılır?

  1. Kod Not Defteri'ne yapıştırılır ve hash_dogrulayici.bat adıyla kaydedilir (Kayıt türü: Tüm dosyalar seçilmelidir; aksi halde dosya .txt olarak kaydedilir).
  2. Dosyaya çift tıklanarak çalıştırılır.
  3. Doğrulanacak dosya, .bat dosyasının üzerine sürüklenip bırakılır; ya da betik çalıştırılıp dosya yolu yazılır.
  4. Algoritma seçilir. Yazılımın indirme sayfasında hangi algoritma yazıyorsa o seçilmelidir (çoğunlukla SHA256).
  5. Sayfadaki özet değeri kopyalanıp istendiğinde yapıştırılır.
@echo off
setlocal EnableExtensions
title [ HASH VERIFIER ] Dosya Butunluk Dogrulayici
color 0A
cls
echo.
echo   ====================================================
echo    [ HASH VERIFIER ]  Dosya Butunluk Dogrulayici
echo   ====================================================
echo.

set "DOSYA=%~1"
if defined DOSYA goto :dosya_var
set /p "DOSYA=Dosya yolu (dosyayi pencereye surukleyebilirsiniz): "
if not defined DOSYA goto :dosya_yok
set "DOSYA=%DOSYA:"=%"
:dosya_var
if not exist "%DOSYA%" goto :dosya_yok

echo.
echo    1. SHA256 ^(onerilen^)
echo    2. SHA512
echo    3. SHA1
echo    4. MD5
echo.
choice /c 1234 /n /m "Algoritma [1-4]: "
set "ALG=SHA256"
if errorlevel 2 set "ALG=SHA512"
if errorlevel 3 set "ALG=SHA1"
if errorlevel 4 set "ALG=MD5"

echo.
echo [*] Ozet hesaplaniyor...
set "HASH="
for /f "skip=1 tokens=* delims=" %%h in ('certutil -hashfile "%DOSYA%" %ALG%') do if not defined HASH set "HASH=%%h"
if not defined HASH goto :hash_hata
set "HASH=%HASH: =%"
echo %HASH%| findstr /r "^[0-9a-fA-F][0-9a-fA-F]*$" >nul || goto :hash_hata

echo.
echo [+] Dosya     : %DOSYA%
echo [+] Algoritma : %ALG%
echo [+] Ozet      : %HASH%
echo.

set "BEKLENEN="
set /p "BEKLENEN=Karsilastirilacak ozet degeri (bos birakilirsa atlanir): "
if not defined BEKLENEN goto :kayit
set "BEKLENEN=%BEKLENEN:"=%"
set "BEKLENEN=%BEKLENEN: =%"
echo.
if /i "%HASH%"=="%BEKLENEN%" goto :eslesti
echo [!] UYUSMUYOR: Dosya bozulmus veya degistirilmis olabilir!
echo     Dosyayi yeniden indirin ve ozet degerinin kaynagini kontrol edin.
goto :kayit

:eslesti
echo [+] DOGRULANDI: Dosya butunlugu saglandi.

:kayit
>>"%~dp0hash_kayitlari.txt" echo %DATE% %TIME:~0,8% ^| %ALG% ^| %HASH% ^| %DOSYA%
echo.
echo [i] Sonuc su dosyaya eklendi: %~dp0hash_kayitlari.txt
echo.
pause
exit /b 0

:dosya_yok
echo [-] Dosya bulunamadi veya yol girilmedi.
echo.
pause
exit /b 1

:hash_hata
echo [-] Ozet hesaplanamadi. Dosya baska bir program tarafindan
echo     kullaniliyor olabilir veya okuma izniniz yok.
echo.
pause
exit /b 1

Kod nasıl çalışıyor?

  • %~1: Betiğe sürüklenen dosyanın yolunu verir. Yol verilmediyse set /p ile kullanıcıdan istenir; %DOSYA:"=% ifadesi yoldaki tırnak işaretlerini temizler.
  • certutil -hashfile: Windows'un yerleşik komutudur ve ek yazılım gerektirmez. Çıktının ilk satırı açıklama, ikinci satırı özet değeridir; skip=1 ilk satırı atlar.
  • Boşlukların temizlenmesi: Bazı Windows sürümleri özeti bayt aralarında boşlukla yazar. %HASH: =% boşlukları siler.
  • Biçim kontrolü: findstr /r "^[0-9a-fA-F][0-9a-fA-F]*$" çıktının gerçekten onaltılık bir özet olduğunu doğrular; hata mesajı özet sanılmaz.
  • Karşılaştırma: if /i büyük/küçük harf farkını yok sayar; çünkü özet değerleri hem büyük hem küçük harfle yazılabilir.
  • Kayıt: >>"%~dp0hash_kayitlari.txt" sonuçları betiğin bulunduğu klasördeki dosyaya ekler.

Sonuçların yorumlanması

  • DOĞRULANDI: Dosya, yayımlanan dosyayla birebir aynıdır.
  • UYUŞMUYOR: Dosya indirme sırasında bozulmuş, eksik inmiş veya değiştirilmiş olabilir. Dosya silinmeli, yeniden indirilmeli ve özet değerinin resmî siteden alındığından emin olunmalıdır.
  • Özet değeri ile dosya aynı siteden indirilmişse, site ele geçirildiğinde ikisi birlikte değiştirilebilir. Mümkünse özet değeri farklı bir kaynaktan (resmî duyuru, GitHub sürüm sayfası) da kontrol edilmelidir.
  • MD5 ve SHA1 algoritmaları kasıtlı değişikliklere karşı artık güvenli kabul edilmez; yalnızca bozulma kontrolü için uygundur.
Betik yalnızca okuma ve raporlama yapar; sistem ayarlarını değiştirmez. Kayıt dosyası dışında hiçbir şey yazmaz.

Batch Uygulamaları

Bilgisayarda dinleyen portları, dışarıya yapılmış aktif bağlantıları ve riskli portları program adlarıyla listeleyen menülü batch uygulaması.

İçindekiler
  1. Ne yapar?
  2. Nasıl kullanılır?
  3. Kod nasıl çalışıyor?
  4. Sonuçların yorumlanması

Bilgisayarda dinleyen her port, ağdan gelebilecek bir erişim noktasıdır. Hangi programın hangi portu açtığını bilmek, gereksiz hizmetleri kapatmak ve şüpheli bağlantıları fark etmek için gereklidir. Bu uygulama, Windows'un yerleşik ağ komutlarıyla üç ayrı rapor sunan bir menü içerir.

Ne yapar?

  • Dinleyen portlar: Bilgisayarınızın bağlantı beklediği TCP portlarını, portu açan programın adıyla listeler. Portun yalnızca bu bilgisayardan mı (YEREL) yoksa ağdan da mı (AG) erişilebilir olduğunu gösterir.
  • Aktif bağlantılar: Bilgisayarınızın dışarıdaki adreslerle kurduğu bağlantıları, ilgili programla birlikte gösterir.
  • Riskli portlar: FTP (21), Telnet (23), RPC (135), NetBIOS (139), SMB (445), Uzak Masaüstü (3389) ve VNC (5900) portlarından ağa açık olanları uyarı olarak işaretler.

Nasıl kullanılır?

  1. Kod Not Defteri'ne yapıştırılır ve port_denetcisi.bat adıyla kaydedilir (Kayıt türü: Tüm dosyalar seçilmelidir; aksi halde dosya .txt olarak kaydedilir).
  2. Dosyaya çift tıklanarak çalıştırılır.
  3. Menüden 1, 2, 3 tuşlarıyla rapor seçilir; 4 çıkıştır. Daha fazla program bilgisi için betik yönetici olarak çalıştırılabilir.
@echo off
setlocal EnableExtensions
title [ PORT WATCH ] Acik Port ve Baglanti Denetcisi
color 0A

:menu
cls
echo.
echo   ====================================================
echo    [ PORT WATCH ]  Acik Port ve Baglanti Denetcisi
echo   ====================================================
echo.
echo    1. Dinleyen portlar ^(disaridan erisim noktalari^)
echo    2. Disariya yapilmis aktif baglantilar
echo    3. Riskli portlar ^(telnet, SMB, RDP, VNC...^)
echo    4. Cikis
echo.
choice /c 1234 /n /m "Seciminiz [1-4]: "
if errorlevel 4 exit /b 0
if errorlevel 3 goto :riskli
if errorlevel 2 goto :aktif
if errorlevel 1 goto :dinleyen
goto :menu

:dinleyen
cls
echo [*] Dinleyen TCP portlari
echo.
echo PORT    ERISIM   ADRES                  PROGRAM
echo ---------------------------------------------------------
powershell -NoProfile -Command "Get-NetTCPConnection -State Listen | Sort-Object LocalPort | ForEach-Object { $n=(Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue).ProcessName; $e='YEREL'; if ($_.LocalAddress -notin '127.0.0.1','::1') { $e='AG' }; '{0,-7} {1,-8} {2,-22} {3}' -f $_.LocalPort,$e,$_.LocalAddress,$n }"
echo.
echo [i] ERISIM = AG ise port, ag uzerindeki diger cihazlardan erisilebilir.
echo [i] ERISIM = YEREL ise port yalnizca bu bilgisayardan erisilebilir.
echo.
pause
goto :menu

:aktif
cls
echo [*] Disariya yapilmis aktif TCP baglantilari
echo.
echo PROGRAM              YEREL PORT  UZAK ADRES            UZAK PORT
echo ---------------------------------------------------------------
powershell -NoProfile -Command "Get-NetTCPConnection -State Established | Where-Object { $_.RemoteAddress -notin '127.0.0.1','::1' } | ForEach-Object { $n=(Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue).ProcessName; '{0,-20} {1,-11} {2,-21} {3}' -f $n,$_.LocalPort,$_.RemoteAddress,$_.RemotePort } | Sort-Object"
echo.
echo [i] Tanimadiginiz bir program bilinmeyen bir adrese baglaniyorsa,
echo     program adini ve adresi arastirin; gerekirse virus taramasi yapin.
echo.
pause
goto :menu

:riskli
cls
echo [*] Riskli kabul edilen portlarin denetimi
echo.
powershell -NoProfile -Command "$r=@{21='FTP (sifresiz)';23='Telnet (sifresiz)';135='RPC';139='NetBIOS';445='SMB';3389='Uzak Masaustu (RDP)';5900='VNC'}; $b=Get-NetTCPConnection -State Listen | Where-Object { ($_.LocalAddress -notin '127.0.0.1','::1') -and $r.ContainsKey([int]$_.LocalPort) } | Sort-Object LocalPort -Unique; if (-not $b) { '[+] Riskli portlarda aga acik dinleme yok.' } else { $b | ForEach-Object { '[!] Port {0,-6} {1}' -f $_.LocalPort,$r[[int]$_.LocalPort] } }"
echo.
echo [i] Gerekli olmayan bir hizmet acik gorunuyorsa hizmeti kapatin
echo     ve guvenlik duvari kurallarini kontrol edin.
echo.
pause
goto :menu

Kod nasıl çalışıyor?

  • choice menüsü: choice /c 1234 yalnızca bu tuşları kabul eder. if errorlevel kontrolleri büyükten küçüğe yazılmalıdır; çünkü if errorlevel N "N veya daha büyük" anlamına gelir.
  • Get-NetTCPConnection: Bağlantı listesini PowerShell nesneleri olarak verir. -State Listen dinleyenleri, -State Established kurulmuş bağlantıları seçer.
  • Program adı: Her bağlantıda OwningProcess (işlem numarası) alınır ve Get-Process ile program adına çevrilir.
  • Erişim ayrımı: Adres 127.0.0.1 veya ::1 ise port yalnızca yerel; 0.0.0.0 veya başka bir adres ise ağdan erişilebilirdir.
  • Riskli port tablosu: PowerShell sözlüğü (@{...}) port numaralarını açıklamalarıyla eşler; ağa açık portlar bu sözlükte aranır.

Sonuçların yorumlanması

  • AG olarak işaretli ve tanımadığınız bir port için program adı araştırılmalıdır. Windows hizmetleri svchost, System gibi adlarla görünür; bunlar normaldir.
  • Uzak Masaüstü, SMB gibi hizmetler kullanılmıyorsa kapatılmalı ve güvenlik duvarında dışarıya kapalı tutulmalıdır.
  • Aktif bağlantılar listesinde bilinmeyen bir programın bilinmeyen bir adrese bağlandığı görülürse virüs taraması yapılmalıdır.
  • Program adı boş görünüyorsa betik yönetici olarak çalıştırılmalıdır; bazı işlemlerin bilgisi yalnızca yönetici yetkisiyle okunabilir.
Betik yalnızca listeleme yapar; hiçbir bağlantıyı veya hizmeti kapatmaz. Bir hizmeti kapatmadan önce ne işe yaradığının araştırılması gerekir.

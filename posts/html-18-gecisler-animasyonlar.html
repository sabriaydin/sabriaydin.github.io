Geçişler ve animasyonlar, arayüzün kullanıcı eylemlerine yumuşak tepki vermesini sağlar. Doğru kullanıldığında dikkat çekmek ve durum değişikliklerini anlaşılır kılmak için yararlıdır; aşırı kullanıldığında ise dikkat dağıtır ve bazı kullanıcılarda rahatsızlık yaratır.

transition: yumuşak geçiş

Normalde :hover gibi bir durumda değişen değer anında değişir. transition bu değişimi belirli bir sürede yayar.

.dugme {
  background: #c0392b;
  color: #fff;
  transition: background 0.3s ease;
}
.dugme:hover {
  background: #8a1f1b;
}

transition kuralı başlangıç durumundaki öğeye yazılır; böylece hem üzerine gelindiğinde hem de ayrılınca geçiş uygulanır.

ParçaAçıklama
transition-propertyHangi özelliğin geçişe tabi olacağı (background, transform, all)
transition-durationSüre: 0.3s veya 300ms
transition-timing-functionHız eğrisi: ease (varsayılan), linear, ease-in, ease-out, ease-in-out
transition-delayBaşlamadan önce beklenecek süre
 
.kart {
  transition: transform 0.2s ease-out, box-shadow 0.2s ease-out;
}

Birden fazla özellik virgülle ayrılarak yazılabilir. all kullanımı kolaydır ancak istenmeyen özelliklerin de geçişe girmesine yol açabilir.

transform: taşıma, ölçekleme, döndürme

İşlevEtkisi
translate(x, y), translateX(), translateY()Öğeyi yatay ve dikey kaydırır.
scale(1.1)Öğeyi büyütür veya küçültür (1 = olduğu gibi).
rotate(15deg)Öğeyi saat yönünde döndürür.
skew(10deg)Öğeyi eğer.
 
.kart:hover {
  transform: translateY(-4px) scale(1.02);
  box-shadow: 0 8px 20px rgb(0 0 0 / 25%);
}
transform ve opacity özellikleri sayfa yerleşimini yeniden hesaplatmadığı için akıcı çalışır. Animasyonlarda width, height, top ve left yerine mümkün olduğunca bu ikisi kullanılmalıdır.

@keyframes: animasyon

Geçiş yalnızca iki durum (önce ve sonra) arasında çalışır. Daha karmaşık, kendiliğinden başlayan veya tekrar eden hareketler için @keyframes ile adımlar tanımlanır ve animation ile öğeye bağlanır.

@keyframes belir {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}

.kutu {
  animation: belir 0.6s ease-out;
}

Adımlar yüzdeyle de yazılabilir:

@keyframes nabiz {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.1); }
  100% { transform: scale(1); }
}

.simge {
  animation: nabiz 1.5s ease-in-out infinite;
}
ÖzellikAçıklama
animation-name@keyframes adı
animation-durationBir turun süresi
animation-iteration-countTekrar sayısı; infinite sonsuz
animation-delayBaşlama gecikmesi
animation-directionnormal, reverse, alternate (gidip gelme)
animation-fill-modeforwards ile animasyon bittiğinde son durumda kalır
animation-play-statepaused ile durdurulur

Örnek: yüklenme göstergesi

<div class="yukleniyor" role="status" aria-label="Yükleniyor"></div>

.yukleniyor {
  width: 40px;
  height: 40px;
  border: 4px solid #ddd;
  border-top-color: #c0392b;
  border-radius: 50%;
  animation: don 0.8s linear infinite;
}
@keyframes don {
  to { transform: rotate(360deg); }
}

Erişilebilirlik: hareketi azaltma

Bazı kullanıcılar için ekrandaki hareket baş dönmesi veya rahatsızlık yaratabilir. İşletim sistemindeki "hareketi azalt" tercihi CSS ile algılanabilir ve animasyonlar kapatılabilir:

@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}

İyi uygulama önerileri

  • Süreler kısa tutulur: arayüz geçişleri için genellikle 150-400 ms yeterlidir.
  • Animasyon bilgi aktarmıyorsa süs için gereğinden fazla kullanılmaz.
  • Saniyede 3 kereden fazla yanıp sönen öğelerden kaçınılır (nöbet riski).
  • Sonsuz animasyonlar, kullanıcı durdurabilecek şekilde veya yalnızca gerektiği sürece çalıştırılır.

Özet

  • transition iki durum arası yumuşak değişim, @keyframes ise çok adımlı veya tekrar eden hareket içindir.
  • transform ve opacity en akıcı çalışan özelliklerdir.
  • prefers-reduced-motion ile hareket tercihi dikkate alınmalıdır.

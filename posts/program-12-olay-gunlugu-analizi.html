Batch Uygulamaları

Windows, oturum açma denemeleri ve hesap değişiklikleri gibi güvenlik olaylarını bir günlükte tutar. Saldırı girişimleri çoğunlukla bu günlükte iz bırakır; ancak günlük binlerce kayıt içerdiği için elle incelenmesi zordur. Bu uygulama, seçilen süre içindeki önemli olayları çıkarıp özetler.

Ne yapar?

  • Başarısız oturum açma (Olay 4625): Toplam sayıyı, en çok deneme yapılan hesap adlarını ve kaynak adresleri gösterir. Parola tahmin saldırıları bu şekilde fark edilir.
  • Hesap değişiklikleri (Olay 4720, 4724, 4726, 4732): Yeni hesap oluşturma, parola sıfırlama, hesap silme ve yerel gruba üye ekleme kayıtlarını zaman sırasıyla listeler.
  • Uzak Masaüstü girişleri (Olay 4624, tür 10): RDP ile başarılı girişlerin sayısını, zamanını, hesap adını ve kaynak adresi gösterir.

Nasıl kullanılır?

  1. Kod Not Defteri'ne yapıştırılır ve olay_gunlugu_analizi.bat adıyla kaydedilir (Kayıt türü: Tüm dosyalar seçilmelidir; aksi halde dosya .txt olarak kaydedilir).
  2. Dosyaya sağ tıklanıp Yönetici olarak çalıştır seçilir. Yönetici yetkisi olmadan betik uyarı verip kapanır.
  3. Kaç saat geriye bakılacağı sorulur. Boş bırakılırsa 24 saat kullanılır.
@echo off
setlocal EnableExtensions
title [ LOG HUNTER ] Guvenlik Olay Gunlugu Analizi
color 0A

net session >nul 2>&1
if %errorlevel% neq 0 (
    echo.
    echo [!] Bu arac yonetici olarak calistirilmalidir.
    echo     Guvenlik olay gunlugu yalnizca yonetici hesabiyla okunabilir.
    echo.
    pause
    exit /b 1
)

cls
echo.
echo   ====================================================
echo    [ LOG HUNTER ]  Guvenlik Olay Gunlugu Analizi
echo   ====================================================
echo.

set "SAAT=24"
set /p "SAAT=Kac saat geriye bakilsin [varsayilan 24]: "
echo %SAAT%| findstr /r "^[0-9][0-9]*$" >nul || set "SAAT=24"

echo.
echo [*] 1/3 Basarisiz oturum acma denemeleri ^(Olay 4625^), son %SAAT% saat
echo.
powershell -NoProfile -Command "$s=(Get-Date).AddHours(-%SAAT%); try { $e=@(Get-WinEvent -FilterHashtable @{LogName='Security';Id=4625;StartTime=$s} -ErrorAction Stop) } catch { $e=@() }; 'Toplam basarisiz deneme: ' + $e.Count; if ($e.Count -gt 0) { ''; 'Hesap adina gore (ilk 10):'; $e | ForEach-Object { ([xml]$_.ToXml()).Event.EventData.Data | Where-Object { $_.Name -eq 'TargetUserName' } | ForEach-Object { $_.'#text' } } | Group-Object | Sort-Object Count -Descending | Select-Object -First 10 | ForEach-Object { '  {0,-6} {1}' -f $_.Count,$_.Name }; ''; 'Kaynak adrese gore (ilk 10):'; $e | ForEach-Object { ([xml]$_.ToXml()).Event.EventData.Data | Where-Object { $_.Name -eq 'IpAddress' } | ForEach-Object { $_.'#text' } } | Group-Object | Sort-Object Count -Descending | Select-Object -First 10 | ForEach-Object { '  {0,-6} {1}' -f $_.Count,$_.Name } }"

echo.
echo [*] 2/3 Hesap degisiklikleri ^(olusturma, silme, parola sifirlama, yerel gruba ekleme^)
echo.
powershell -NoProfile -Command "$s=(Get-Date).AddHours(-%SAAT%); $m=@{4720='Hesap olusturuldu';4724='Parola sifirlandi';4726='Hesap silindi';4732='Yerel gruba uye eklendi'}; try { $e=@(Get-WinEvent -FilterHashtable @{LogName='Security';Id=4720,4724,4726,4732;StartTime=$s} -ErrorAction Stop) } catch { $e=@() }; if ($e.Count -eq 0) { '[+] Kayit yok.' } else { $e | Sort-Object TimeCreated | ForEach-Object { '[!] {0:dd.MM HH:mm}  {1}' -f $_.TimeCreated,$m[[int]$_.Id] } }"

echo.
echo [*] 3/3 Uzak Masaustu ^(RDP^) ile basarili girisler ^(Olay 4624, tur 10^)
echo.
powershell -NoProfile -Command "$s=(Get-Date).AddHours(-%SAAT%); try { $e=@(Get-WinEvent -FilterHashtable @{LogName='Security';Id=4624;StartTime=$s} -ErrorAction Stop | Where-Object { $d=([xml]$_.ToXml()).Event.EventData.Data; ($d | Where-Object { $_.Name -eq 'LogonType' }).'#text' -eq '10' }) } catch { $e=@() }; if ($e.Count -eq 0) { '[+] RDP ile basarili giris yok.' } else { '[!] RDP ile basarili giris sayisi: ' + $e.Count; $e | Select-Object -First 5 | ForEach-Object { $d=([xml]$_.ToXml()).Event.EventData.Data; '    {0:dd.MM HH:mm}  {1}  {2}' -f $_.TimeCreated,($d | Where-Object { $_.Name -eq 'TargetUserName' }).'#text',($d | Where-Object { $_.Name -eq 'IpAddress' }).'#text' } }"

echo.
echo ----------------------------------------------------------
echo [i] Degerlendirme ipuclari:
echo     - Ayni hesap veya adrese yuzlerce basarisiz deneme, parola
echo       tahmin saldirisina isaret edebilir; parolayi degistirin ve
echo       gerekmiyorsa Uzak Masaustu erisimini kapatin.
echo     - Sizin yapmadiginiz hesap olusturma veya yetki degisikligi
echo       ciddi bir uyaridir; hesaplari ve yoneticiler grubunu inceleyin.
echo     - Gunluk kayitlari dolunca eski kayitlar silinir; uzun sure
echo       geriye gitmek icin yeterli veri olmayabilir.
echo.
pause
exit /b 0

Kod nasıl çalışıyor?

  • Saat doğrulaması: echo %SAAT%| findstr /r "^[0-9][0-9]*$" girilen değerin yalnızca rakam olduğunu denetler; değilse || ile varsayılan değer 24 atanır.
  • Get-WinEvent -FilterHashtable: Olay günlüğünü kimlik numarası ve başlangıç zamanına göre filtreler; büyük günlüklerde yalnızca ilgili kayıtları okuduğu için hızlıdır.
  • Hata yakalama: Belirtilen sürede hiç olay yoksa Get-WinEvent hata verir. try ... catch bu durumu boş liste olarak ele alır.
  • XML ayrıştırma: Hesap adı ve IP adresi gibi ayrıntılar olayın XML verisinde saklanır. ToXml() ile okunan veriden TargetUserName, IpAddress ve LogonType alanları alınır.
  • Gruplama: Group-Object aynı hesap veya adresin kaç kez göründüğünü sayar; Sort-Object Count -Descending en çok görünenleri başa alır.

Sonuçların yorumlanması

  • Aynı hesap veya adresten kısa sürede yüzlerce başarısız deneme, parola tahmin saldırısı olabilir. Parolanın güçlendirilmesi ve gerekmiyorsa Uzak Masaüstü erişiminin kapatılması gerekir.
  • Kullanıcı adı olarak Administrator, admin, test gibi genel adların denendiği görülüyorsa otomatik tarama araçları sisteme erişmeye çalışıyor olabilir.
  • Kullanıcının kendisinin yapmadığı hesap oluşturma veya yetki değişikliği ciddi bir uyarıdır; hesaplar ve Yöneticiler grubu incelenmelidir.
  • Kaynak adres - olarak görünüyorsa deneme yerel olarak yapılmıştır. Parolasını yanlış yazan bir kullanıcı da bu kaydı oluşturabilir.
  • Güvenlik günlüğünün boyutu sınırlıdır; dolduğunda eski kayıtlar silinir. Uzun süre geriye gitmek için yeterli veri bulunmayabilir.
Betik yalnızca okuma ve raporlama yapar; sistem ayarlarını değiştirmez. Olay günlüğünü silmez veya değiştirmez.

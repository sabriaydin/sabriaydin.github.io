Batch Uygulamaları

Windows Defender, güvenlik duvarı, UAC, BitLocker, Secure Boot, SMBv1 ve Uzak Masaüstü ayarlarını tek seferde denetleyip riskli bulguları listeleyen batch uygulaması.

İçindekiler
  1. Ne yapar?
  2. Nasıl kullanılır?
  3. Kod nasıl çalışıyor?
  4. Sonuçların yorumlanması

Bir bilgisayarınızın güvenliği, tek bir ayardan değil birbirini tamamlayan birçok korumadan oluşur. Bu uygulama, en önemli on koruma ayarını sırayla denetler, her birini [+] güvenli, [!] risk veya [?] belirlenemedi olarak işaretler ve sonda özet verir. Beyaz şapkalı güvenlik uzmanlarının "önce kendi sistemini denetle" yaklaşımından esinlenmiştir ve yalnızca okuma yapar.

Ne yapar?

  • Microsoft Defender gerçek zamanlı koruma durumunu ve virüs imzalarının yaşını kontrol eder.
  • Güvenlik duvarının üç profilinin (Etki Alanı, Özel, Genel) açık olup olmadığına bakar.
  • Kullanıcı Hesabı Denetimi (UAC), BitLocker, Secure Boot durumlarını okur.
  • Konuk hesabı, SMBv1 protokolü ve Uzak Masaüstü (RDP) gibi saldırı yüzeyini büyüten ayarların açık olup olmadığını denetler.
  • Sonuçta kontrol sayısını ve riskli bulgu sayısını özetler.

Nasıl kullanılır?

  1. Kod Not Defteri'ne yapıştırılır ve guvenlik_denetimi.bat adıyla kaydedilir (Kayıt türü: Tüm dosyalar seçilmelidir; aksi halde dosya .txt olarak kaydedilir).
  2. Dosyaya sağ tıklanıp Yönetici olarak çalıştır seçilir. Yönetici yetkisi olmadan betik uyarı verip kapanır.
@echo off
setlocal EnableExtensions
title [ SECURITY AUDIT ] Yerel Sistem Guvenlik Denetimi
color 0A

net session >nul 2>&1
if %errorlevel% neq 0 (
    echo.
    echo [!] Bu arac yonetici olarak calistirilmalidir.
    echo     Dosyaya sag tiklayip "Yonetici olarak calistir" secin.
    echo.
    pause
    exit /b 1
)

set /a TOPLAM=0
set /a RISK=0

cls
echo.
echo   ====================================================
echo    [ SECURITY AUDIT ]  Yerel Sistem Guvenlik Denetimi
echo   ====================================================
echo    Bilgisayar : %COMPUTERNAME%
echo    Kullanici  : %USERNAME%
echo    Tarih      : %DATE% %TIME:~0,8%
echo   ====================================================
echo.
echo [*] Denetim basliyor...
echo.

call :ps DEF "(Get-MpComputerStatus).RealTimeProtectionEnabled"
call :degerlendir "Defender gercek zamanli koruma" "%DEF%" "True"

call :ps IMZA "(New-TimeSpan -Start (Get-MpComputerStatus).AntivirusSignatureLastUpdated -End (Get-Date)).Days"
set /a TOPLAM+=1
if "%IMZA%"=="Bilinmiyor" goto :imza_bilinmiyor
if %IMZA% GTR 7 goto :imza_eski
echo [+] Virus imzalari: guncel ^(%IMZA% gun once guncellendi^)
goto :imza_son
:imza_bilinmiyor
echo [?] Virus imzalari: belirlenemedi
goto :imza_son
:imza_eski
echo [!] Virus imzalari: %IMZA% gundur guncellenmemis
set /a RISK+=1
:imza_son

call :ps FW "(Get-NetFirewallProfile | Where-Object { -not $_.Enabled }).Count"
call :degerlendir "Kapali guvenlik duvari profili sayisi" "%FW%" "0"

call :reg UAC "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" "EnableLUA"
call :degerlendir "Kullanici Hesabi Denetimi (UAC) acik" "%UAC%" "0x1"

call :ps BL "try { (Get-BitLockerVolume -MountPoint $env:SystemDrive -ErrorAction Stop).ProtectionStatus } catch { 'Bilinmiyor' }"
call :degerlendir "BitLocker sistem surucusu korumasi" "%BL%" "On"

call :ps SB "try { Confirm-SecureBootUEFI } catch { 'Bilinmiyor' }"
call :degerlendir "Secure Boot etkin" "%SB%" "True"

call :ps GUEST "(Get-LocalUser | Where-Object { $_.SID.Value -like '*-501' }).Enabled"
call :degerlendir "Konuk hesabi etkin" "%GUEST%" "False"

call :ps SMB1 "(Get-SmbServerConfiguration).EnableSMB1Protocol"
call :degerlendir "SMBv1 protokolu etkin" "%SMB1%" "False"

call :reg RDP "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" "fDenyTSConnections"
call :degerlendir "Uzak Masaustu (RDP) kapali" "%RDP%" "0x1"

echo.
echo   ----------------------------------------------------
echo    Yapilan kontrol : %TOPLAM%
echo    Riskli bulgu    : %RISK%
echo   ----------------------------------------------------
if %RISK% EQU 0 goto :temiz
echo [!] Riskli bulgular icin ilgili ayari gozden gecirin.
goto :son
:temiz
echo [+] Belirgin bir risk bulunmadi.
:son
echo.
pause
exit /b 0

rem ---------- Alt programlar ----------

:ps
rem %1 = degisken adi, %2 = PowerShell ifadesi
set "%~1=Bilinmiyor"
for /f "delims=" %%i in ('powershell -NoProfile -Command "%~2" 2^>nul') do set "%~1=%%i"
exit /b

:reg
rem %1 = degisken adi, %2 = anahtar, %3 = deger adi
set "%~1=Bilinmiyor"
for /f "tokens=3" %%a in ('reg query "%~2" /v %~3 2^>nul ^| findstr /i "%~3"') do set "%~1=%%a"
exit /b

:degerlendir
rem %1 = aciklama, %2 = bulunan deger, %3 = guvenli deger
set /a TOPLAM+=1
if /i "%~2"=="Bilinmiyor" goto :deg_bilinmiyor
if /i "%~2"=="%~3" goto :deg_iyi
echo [!] %~1: RISK ^(deger: %~2^)
set /a RISK+=1
exit /b
:deg_iyi
echo [+] %~1: guvenli
exit /b
:deg_bilinmiyor
echo [?] %~1: belirlenemedi
exit /b

Kod nasıl çalışıyor?

  • Yönetici denetimi: net session komutu yalnızca yönetici yetkisiyle başarılı olur; başarısız olursa betik açıklama yazıp çıkar.
  • :ps alt programı: Verilen PowerShell ifadesini çalıştırıp çıktısını bir değişkene yazar. Çıktı alınamazsa değişken Bilinmiyor olarak kalır; böylece desteklenmeyen özellikler (örneğin Windows Home'da BitLocker) betiği bozmaz.
  • :reg alt programı: reg query ile kayıt defteri değerini okur. tokens=3 çıktı satırının üçüncü parçasını (değeri) alır.
  • :degerlendir alt programı: Bulunan değeri beklenen güvenli değerle karşılaştırır, sonucu işaretler ve sayaçları günceller.
  • Dilden bağımsızlık: Türkçe Windows'ta komut çıktıları Türkçe olabileceği için betik, çıktı metnini ayrıştırmak yerine PowerShell nesnelerinin değerlerini ve kayıt defteri değerlerini okur.

Sonuçların yorumlanması

  • [+] güvenli: değer beklenen güvenli değerle aynı.
  • [!] risk: ilgili ayar önerilen değerden farklı. Parantez içinde bulunan değer gösterilir.
  • [?] belirlenemedi: özellik sistemde bulunmuyor veya okunamadı (örneğin üçüncü taraf antivirüs kullanıldığında Defender bilgisi alınamaz). Bu bir risk anlamına gelmez.
  • Uzak Masaüstü ve SMBv1 gerçekten kullanılmıyorsa kapalı olması önerilir. Kullanılıyorsa yalnızca güvenilir ağlarda ve güçlü parolayla açık tutulmalıdır.
Bu denetim bir güvenlik sertifikası değildir; yalnızca yaygın ayarları kontrol eder. Betik yalnızca okuma ve raporlama yapar; sistem ayarlarını değiştirmez.

Batch Uygulamaları

Bilgisayarda kayıtlı tüm Wi-Fi ağlarının kimlik doğrulama ve şifreleme türünü okuyup WEP, WPA/TKIP ve açık ağları işaretleyen batch uygulaması.

İçindekiler

  3. Kod nasıl çalışıyor?
  4. Sonuçların yorumlanması

Bilgisayarlar bağlandıkları Wi-Fi ağlarını hatırlar ve yakında aynı ada sahip bir ağ gördüklerinde otomatik bağlanabilir. Eski ve zayıf şifreleme kullanan ağlar ise saldırganlara kolay hedef sunar. Bu uygulama, kayıtlı ağların güvenlik türlerini listeler ve zayıf olanları işaretler. Wi-Fi parolalarını okumaz ve göstermez.

Ne yapar?

  • Tüm kayıtlı Wi-Fi profillerini geçici klasöre dışa aktarır (parolalar dahil edilmez).
  • Her ağ için kimlik doğrulama (WPA2PSK, WPA3SAE, open vb.) ve şifreleme (AES, TKIP, WEP, none) türünü okur.
  • Ağları iyi, eski (WPA/TKIP), zayıf (WEP) veya açık ağ olarak sınıflandırır.
  • O anda bağlı olunan ağın ayrıntılarını gösterir.
  • İşlem bitince geçici dosyaları siler.

Nasıl kullanılır?

  1. Kod Not Defteri'ne yapıştırılır ve wifi_guvenlik_denetimi.bat adıyla kaydedilir (Kayıt türü: Tüm dosyalar seçilmelidir; aksi halde dosya .txt olarak kaydedilir).
  2. Dosyaya çift tıklanarak çalıştırılır.
  3. Betik, bilgisayarda Wi-Fi bağdaştırıcısı olması halinde çalışır.
  4. Listede ZAYIF veya ACIK AG olarak işaretlenen ağlar için güvenlik önerileri uygulanır.
@echo off
setlocal EnableExtensions
title [ WIFI GUARD ] Kayitli Wi-Fi Guvenlik Denetimi
color 0A
cls
echo.
echo   ====================================================
echo    [ WIFI GUARD ]  Kayitli Wi-Fi Guvenlik Denetimi
echo   ====================================================
echo.

set "CIKTI=%TEMP%\wifi_denetim"
if exist "%CIKTI%" rd /s /q "%CIKTI%"
md "%CIKTI%"

echo [*] Kayitli Wi-Fi profilleri okunuyor ^(parolalar okunmaz^)...
netsh wlan export profile folder="%CIKTI%" >nul 2>&1
dir /b "%CIKTI%\*.xml" >nul 2>&1
if errorlevel 1 goto :yok

echo.
echo AG ADI                         KIMLIK DOGRULAMA  SIFRELEME  DURUM
echo ----------------------------------------------------------------------------
powershell -NoProfile -Command "Get-ChildItem '%CIKTI%\*.xml' | ForEach-Object { [xml]$x=Get-Content -LiteralPath $_.FullName -Encoding UTF8; $a=$x.WLANProfile.MSM.security.authEncryption; $d='[+] iyi'; if ($a.encryption -eq 'WEP' -or $a.authentication -eq 'shared') { $d='[!] ZAYIF (WEP)' } elseif ($a.authentication -eq 'open' -or $a.encryption -eq 'none') { $d='[!] ACIK AG' } elseif ($a.encryption -eq 'TKIP' -or $a.authentication -in 'WPA','WPAPSK') { $d='[~] ESKI (WPA/TKIP)' }; '{0,-30} {1,-17} {2,-10} {3}' -f $x.WLANProfile.name,$a.authentication,$a.encryption,$d }"

echo.
echo [*] Su an bagli olunan ag:
echo.
netsh wlan show interfaces

rd /s /q "%CIKTI%"
echo.
echo [i] Degerlendirme:
echo     [+] iyi   : WPA2/WPA3 ve AES sifreleme.
echo     [~] ESKI  : WPA veya TKIP; mumkunse yonlendiricide WPA2/WPA3 + AES secin.
echo     [!] ZAYIF : WEP dakikalar icinde kirilabilir; kullanmayin.
echo     [!] ACIK  : Sifresiz aglarda trafik izlenebilir; VPN olmadan hassas
echo                 islem yapmayin ve gereksiz ise profili silin.
echo.
echo [i] Profili silmek icin: netsh wlan delete profile name="AG ADI"
echo.
pause
exit /b 0

:yok
echo.
echo [-] Kayitli Wi-Fi profili bulunamadi veya bu bilgisayarda Wi-Fi
echo     bulunmuyor.
rd /s /q "%CIKTI%" 2>nul
echo.
pause
exit /b 1

Kod nasıl çalışıyor?

  • Profil dışa aktarma: netsh wlan export profile her profili XML dosyası olarak yazar. key=clear parametresi kullanılmadığı için parolalar dosyaya yazılmaz.
  • Dilden bağımsız okuma: netsh wlan show profiles çıktısı Windows diline göre değiştiği için betik bu çıktıyı ayrıştırmaz; bunun yerine dili hiç değişmeyen XML etiketlerini (authentication, encryption) okur.
  • Sınıflandırma: PowerShell, encryption değeri WEP olanları zayıf, open/none olanları açık, TKIP veya WPA/WPAPSK olanları eski olarak işaretler; kalanlar iyi kabul edilir.
  • Temizlik: İşlem sonunda rd /s /q ile geçici klasör silinir.

Sonuçların yorumlanması

  • iyi: WPA2 veya WPA3 ile AES kullanan ağlar güncel kabul edilir.
  • ESKİ (WPA/TKIP): Yönlendirici ayarlarından WPA2/WPA3 ve AES seçilmelidir.
  • ZAYIF (WEP): WEP dakikalar içinde kırılabilir. Bu ağ kullanılmamalı, yönlendirici ayarları güncellenmelidir.
  • AÇIK AĞ: Şifresiz ağlarda trafik başkaları tarafından izlenebilir. Hassas işlemler VPN olmadan yapılmamalı, kullanılmayan açık ağ profilleri netsh wlan delete profile name="AĞ ADI" komutuyla silinmelidir.
Betik hiçbir profili silmez veya değiştirmez. Kayıtlı Wi-Fi parolalarını başkalarının bilgisayarında görüntülemek, izinsiz erişim sayılabilir.

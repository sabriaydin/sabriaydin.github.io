İçeriğe geç

Ortam değişkenleri, Windows ve programların ortak kullandığı adlandırılmış değerlerdir. PATH değişkeni, komutların hangi klasörlerde aranacağını belirler. Batch betiklerinde bunları okumayı, geçici veya kalıcı değiştirmeyi bilmek, betiklerin farklı bilgisayarlarda çalışabilmesi için gereklidir.

Ortam değişkenlerini görüntüleme

set                    rem tum degiskenleri listeler
set PATH               rem adi PATH ile baslayanlari listeler
echo %PATH%            rem PATH'in degerini yazar
echo %USERPROFILE%     rem C:\Users\kullanici
where notepad          rem bir komutun/programin bulundugu yeri gosterir

PATH içindeki klasörleri alt alta görmek için:

@echo off
for %%p in ("%PATH:;=" "%") do echo %%~p
pause

Kapsam: üç seviye

SeviyeNasıl ayarlanır?Ne kadar sürer?
Süreç (geçici)set ADI=degerYalnızca o komut penceresi ve o penceredeki betik çalışırken
Kullanıcı (kalıcı)setx ADI degerBu kullanıcının sonradan açılan pencerelerinde
Bilgisayar (kalıcı)setx ADI deger /M (yönetici gerekir)Tüm kullanıcılar için, sonradan açılan pencerelerde
 
@echo off
rem Geçici: yalnizca bu pencere
set "PROJE=C:\Projeler"

rem Kalici (kullanici duzeyinde)
setx PROJE "C:\Projeler"

rem setx, MEVCUT pencerede degeri degistirmez:
echo %PROJE%     rem setx'ten once ne varsa o gorunur
pause
  • setx değeri hemen mevcut pencereye yansıtmaz; yeni açılan pencerelerde görünür.
  • setx ile yazılan değer 1024 karakterle sınırlıdır; daha uzun değerler sessizce kesilir.
  • setx PATH "%PATH%;C:\Araclar" komutu, kullanıcı ve sistem PATH değerlerini birleştirip yalnızca kullanıcıya yazar, kopya ve kesilme sorunlarına yol açar. PATH için setx kullanılmamalıdır.

PATH'e güvenli klasör ekleme

Yalnızca betik çalışırken (geçici)

@echo off
setlocal
set "PATH=%PATH%;C:\Araclar"
aractan_biri.exe
endlocal

Kalıcı (kullanıcı düzeyinde)

Kalıcı değişiklik için PowerShell yöntemi setx'in sorunlarına yol açmaz:

powershell -NoProfile -Command "$y=[Environment]::GetEnvironmentVariable('Path','User'); if ($y -notlike '*C:\Araclar*') { [Environment]::SetEnvironmentVariable('Path', ($y.TrimEnd(';') + ';C:\Araclar'), 'User') }"

Komut, klasör zaten ekliyse tekrar eklemez. Değişiklik yeni açılan pencerelerde geçerli olur. Grafik arayüzle yapmak için: Başlat > "ortam değişkenleri" > Ortam Değişkenlerini Düzenle > Path.

setlocal ve endlocal

setlocal, betiğin yaptığı değişken değişikliklerini betik bitince (veya endlocal komutuyla) geri alır. Böylece betik, çağıran pencerenin değişkenlerini bozmaz.

@echo off
setlocal
set "GECICI=Sadece bu betikte gecerli"
echo %GECICI%
endlocal
echo [%GECICI%]      rem bos: degisken silindi

Bir alt programın hesapladığı değeri setlocal bloğunun dışına çıkarmak için şu yöntem kullanılır:

@echo off
call :hesapla
echo Sonuc: %SONUC%
pause
exit /b

:hesapla
setlocal
set /a ARA=6*7
endlocal & set "SONUC=%ARA%"
exit /b

endlocal & set "SONUC=%ARA%" satırında %ARA% genişletmesi, endlocal çalışmadan önce yapıldığı için değer korunur.

Komut arama sırası

Bir komut yazıldığında Windows şu sırayla arar: yerleşik komutlar (dir, echo...), geçerli klasör, ardından PATH içindeki klasörler. Her klasörde PATHEXT değişkenindeki uzantılar sırayla denenir (.COM, .EXE, .BAT, .CMD...).

  • Betiğe ping.bat, net.bat, test.bat gibi mevcut komut adları verilmemelidir. Betik içinde ping yazıldığında kendi kendini çağırabilir.
  • Aynı adlı komutlardan hangisinin çalışacağını where komut gösterir.
  • PATH içinde güvenilmeyen veya herkesin yazabildiği klasör bulunmamalıdır; saldırgan oraya sahte program koyabilir.

Özet

  • set geçici, setx kalıcıdır; setx mevcut pencereyi etkilemez ve 1024 karakterle sınırlıdır.
  • PATH değişikliği için setx yerine geçici set veya PowerShell kullanılır.
  • Sabit yollar yerine %USERPROFILE%, %APPDATA% gibi değişkenler kullanılır.
  • setlocal/endlocal değişken değişikliklerini betikle sınırlar; endlocal & set değeri dışarı çıkarır.

Batch Rehberi

choice ve set /p ile seçenekli menü kurmayın, menüye geri dönen döngü, cls, color, title ve timeout kullanımı.

İçindekiler
  1. choice ile menü
  2. Evet/Hayır sorusu
  3. set /p ile menü
  4. Görünümü düzenleme

Birden fazla işi yapan bir script'i kullanışlı hale getirmenin yolu menüdür. Menü için iki yöntem var: tek tuşla seçim yaptıran choice ve yazıp Enter'a basılan set /p.

choice ile menü

@echo off
title Ana Menu

:menu
cls
echo ==============================
echo          ANA MENU
echo ==============================
echo  1) Not Defteri'ni ac
echo  2) Hesap makinesini ac
echo  3) Cikis
echo.
choice /c 123 /n /m "Seciminiz (1-3): "
if errorlevel 3 goto :cikis
if errorlevel 2 goto :hesap
if errorlevel 1 goto :notdefteri

:notdefteri
start notepad
goto :menu

:hesap
start calc
goto :menu

:cikis
exit /b
  • choice /c 123 kabul edilen tuşları belirler. /n tuş listesini gizler, /m mesaj yazar.
  • Basılan tuşun sırası errorlevel olarak döner: 1. tuş için 1, 2. tuş için 2...
  • if errorlevel n "n veya daha büyük" demek olduğundan kontroller büyükten küçüğe yazılır. Küçükten başlarsanız her seçim 1. satırı yakalar.
  • Her bölüm goto :menu ile bitmeli; yoksa akış bir sonraki etikete düşer.

Evet/Hayır sorusu

choice /c EH /n /m "Devam edilsin mi? (E/H): "
if errorlevel 2 (
    echo Iptal edildi.
    exit /b
)
echo Devam ediliyor...

set /p ile menü

Kullanıcının bir isim veya yol yazması gereken yerlerde set /p kullanın. Geçersiz bir giriş olursa menüye geri döner:

@echo off
:menu
cls
echo 1) Selam ver
echo 2) Tarihi goster
echo 3) Cikis
echo.
set "secim="
set /p "secim=Seciminiz: "
if "%secim%"=="1" goto :selam
if "%secim%"=="2" goto :tarih
if "%secim%"=="3" exit /b
echo Gecersiz secim!
timeout /t 2 >nul
goto :menu

:selam
set /p "ad=Adin: "
echo Merhaba %ad%!
pause
goto :menu

:tarih
echo Bugun: %date%
pause
goto :menu

set "secim=" satırı, bir önceki turdaki seçimin kalmasını önler. Kullanıcı sadece Enter'a basarsa set /p değişkeni değiştirmez; bu satır olmasaydı eski seçim tekrar çalışırdı.

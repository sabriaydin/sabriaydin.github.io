İçeriğe geç

Duyarlı (responsive) tasarım, bir sayfanın telefon, tablet ve bilgisayar ekranlarında ayrı sayfa hazırlamadan düzgün görünmesini sağlar. Günümüzde ziyaretlerin büyük bölümü mobil cihazlardan geldiği için sayfaların bu şekilde hazırlanması gerekir.

1. viewport etiketi

Her sayfanın head bölümünde aşağıdaki etiket bulunmalıdır. Bu etiket olmadan mobil tarayıcılar sayfayı masaüstü genişliğinde çizip küçülterek gösterir ve @media kuralları beklendiği gibi çalışmaz.

<meta name="viewport" content="width=device-width, initial-scale=1">

2. Esnek genişlikler ve görseller

  • Sabit width: 960px yerine max-width: 960px ve width: 100% kullanılır; böylece öğe dar ekrana sığar.
  • Görseller kapsayıcısından taşmaması için max-width: 100%; height: auto; ile sınırlanır.
  • Boşluklarda ve yazı boyutlarında px yerine rem ve % tercih edilir.
.sayfa { width: 100%; max-width: 960px; margin: 0 auto; padding: 0 1rem; }
img    { max-width: 100%; height: auto; }

3. @media kuralları

@media, yalnızca belirli koşul sağlandığında uygulanan kurallar tanımlar. En sık kullanılan koşul ekran genişliğidir.

.kartlar {
  display: grid;
  grid-template-columns: 1fr;       /* varsayılan: tek sütun (mobil) */
  gap: 1rem;
}

@media (min-width: 600px) {
  .kartlar { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 900px) {
  .kartlar { grid-template-columns: repeat(3, 1fr); }
}

Bu yaklaşıma mobil öncelikli tasarım denir: önce en dar ekran için temel kurallar yazılır, daha geniş ekranlar için min-width ile eklemeler yapılır. Bu, hem daha az kod gerektirir hem de mobil cihazlarda gereksiz kuralların işlenmesini önler.

Sık kullanılan kırılma noktaları

GenişlikCihaz sınıfı
600pxBüyük telefon, küçük tablet
768pxTablet
1024pxKüçük dizüstü
1280pxMasaüstü

Bu değerler kesin kurallar değildir. En doğru kırılma noktası, tasarımın bozulmaya başladığı genişliktir: tarayıcı penceresi daraltılırken düzen bozulduğunda o genişliğe bir @media kuralı yazılır.

Diğer koşullar

@media (max-width: 599px) { }                 /* dar ekran */
@media (min-width: 600px) and (max-width: 899px) { }
@media (orientation: landscape) { }           /* yatay ekran */
@media (prefers-color-scheme: dark) { }       /* koyu tema tercihi */
@media (prefers-reduced-motion: reduce) { }   /* animasyonu azaltma tercihi */
@media print { }                              /* yazdırma */

4. Akıcı yazı boyutu: clamp()

clamp(en küçük, tercih edilen, en büyük) ile yazı boyutu ekran genişliğiyle birlikte, belirlenen sınırlar içinde değişir:

h1 {
  font-size: clamp(1.75rem, 4vw + 1rem, 3rem);
}

5. Duyarlı görsel seçimi

Farklı ekranlara farklı boyutta görsel sunmak sayfa yüklenme süresini kısaltır:

<img src="kucuk.jpg"
     srcset="kucuk.jpg 480w, orta.jpg 800w, buyuk.jpg 1600w"
     sizes="(min-width: 900px) 800px, 100vw"
     alt="Görsel açıklaması">

6. Dokunmatik ekranlar için notlar

  • Düğme ve bağlantılar parmakla rahat basılabilmesi için yaklaşık 44x44 piksel hedeflenmelidir.
  • :hover etkisine bağlı bilgi, dokunmatik cihazlarda görünmeyebileceği için tek başına kullanılmamalıdır.
  • Yazı boyutu gövde metninde en az 16px (1rem) olmalıdır; daha küçük metinde bazı mobil tarayıcılar form alanlarına yaklaştırma uygular.

Test etme

  1. Tarayıcıda F12 tuşuyla geliştirici araçları açılır.
  2. Ctrl + Shift + M ile cihaz modu açılır; telefon ve tablet boyutları seçilebilir veya genişlik elle değiştirilebilir.
  3. Yatay kaydırma çubuğu çıkıyorsa taşan bir öğe vardır; çoğunlukla sabit genişlikli bir öğe nedenidir.
  4. Mümkünse sayfa gerçek bir telefonda da kontrol edilmelidir.

Özet

  • viewport etiketi her sayfada bulunmalıdır.
  • Sabit genişlik yerine max-width ve yüzde kullanılır; görsellere max-width: 100% verilir.
  • Önce mobil görünüm yazılır, @media (min-width: ...) ile geniş ekranlar için eklemeler yapılır.
  • Esnek düzenler için Flexbox ve Grid (auto-fit, minmax) kullanılır.

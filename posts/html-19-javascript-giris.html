HTML sayfanın yapısını, CSS görünümünü belirler. JavaScript ise sayfaya davranış kazandırır: düğmeye tıklanınca bir şeyin olması, formdaki verinin denetlenmesi, hesaplamalar, içeriğin değiştirilmesi gibi. Bu yazıda sayfaya etkileşim eklemek için gereken temel bilgiler verilir.

JavaScript'i sayfaya ekleme

<!-- Dış dosya (önerilen) -->
<script src="betik.js" defer></script>

<!-- Veya sayfa içinde -->
<script>
  console.log("Sayfa yüklendi");
</script>
  • defer, betiğin sayfa tamamen yüklendikten sonra çalışmasını sağlar. Böylece betik, sayfadaki öğelere erişmeye çalışırken öğelerin henüz yüklenmemiş olması sorunu yaşanmaz.
  • Betik dosyası head içine defer ile ya da </body> kapanışından hemen önce eklenir.

Yazılan kodun çıktısı ve hataları tarayıcıdaki Konsolda görülür (F12 tuşu, ardından Console sekmesi). console.log() ile değerler konsola yazdırılabilir.

Değişkenler ve veri türleri

const ad = "Ayşe";       // değişmeyecek değer
let puan = 10;           // değişebilecek değer
puan = puan + 5;         // 15

const aktif = true;                 // mantıksal (true / false)
const liste = ["elma", "armut"];    // dizi
const kisi = { ad: "Ali", yas: 30 };// nesne

console.log(kisi.ad);      // Ali
console.log(liste[0]);     // elma
  • const: Değeri sonradan değiştirilmeyecek değişkenler için. Varsayılan tercih olmalıdır.
  • let: Değeri değişecek değişkenler için.
  • var eski yöntemdir; yeni kodda kullanılması önerilmez.
  • Metinler tırnak (" veya ') içinde yazılır. Değişken içeren metinler için ters tırnakla yazılan "şablon dizeleri" de vardır (örn. Merhaba ${ad}).

DOM: sayfa öğelerine erişme

Tarayıcı HTML sayfasını bir ağaç yapısına (DOM) dönüştürür. JavaScript bu yapıdaki öğeleri seçip değiştirebilir.

const baslik = document.querySelector("h1");        // ilk h1
const kutu = document.getElementById("kutu");       // id="kutu"
const kartlar = document.querySelectorAll(".kart"); // tüm .kart öğeleri

baslik.textContent = "Yeni başlık";    // metni değiştir
kutu.classList.add("aktif");           // sınıf ekle
kutu.classList.toggle("gizli");        // sınıf varsa kaldır, yoksa ekle
kutu.style.color = "red";              // satır içi stil
  • querySelector() CSS seçicisi alır ve ilk eşleşen öğeyi döndürür; querySelectorAll() tümünü döndürür.
  • Metin değiştirmek için textContent kullanılır.
  • Stil değişiklikleri için doğrudan style yerine CSS sınıflarını classList ile eklemek ve kaldırmak daha düzenlidir.
Kullanıcıdan gelen metin, innerHTML ile sayfaya yazılmamalıdır; zararlı kod çalıştırılmasına (XSS) yol açabilir. Metin için textContent kullanılmalıdır.

Olaylar: kullanıcı eylemlerine tepki verme

addEventListener ile bir öğeye, belirli bir olay gerçekleştiğinde çalışacak fonksiyon bağlanır.

OlayNe zaman gerçekleşir?
clickÖğeye tıklandığında
inputBir form alanına her yazıldığında
changeSeçim veya değer değiştiğinde
submitForm gönderildiğinde
keydownKlavyede tuşa basıldığında
DOMContentLoadedSayfa yapısı yüklendiğinde

Örnek 1: Sayaç

<button id="artir">Artır</button>
<p>Sayı: <span id="sayi">0</span></p>

<script>
  let sayac = 0;
  const sayi = document.getElementById("sayi");

  document.getElementById("artir").addEventListener("click", () => {
    sayac++;
    sayi.textContent = sayac;
  });
</script>

Örnek 2: Yazılan metni anında gösterme

<label for="ad">Ad:</label>
<input type="text" id="ad">
<p id="selam"></p>

<script>
  const alan = document.getElementById("ad");
  const selam = document.getElementById("selam");

  alan.addEventListener("input", () => {
    selam.textContent = alan.value ? "Merhaba " + alan.value : "";
  });
</script>

Örnek 3: Form denetimi

<form id="form">
  <label for="eposta">E-posta:</label>
  <input type="email" id="eposta">
  <button type="submit">Gönder</button>
  <p id="hata" role="alert"></p>
</form>

<script>
  document.getElementById("form").addEventListener("submit", (e) => {
    const eposta = document.getElementById("eposta").value.trim();
    if (!eposta.includes("@")) {
      e.preventDefault();   // formun gönderilmesini durdurur
      document.getElementById("hata").textContent = "Geçerli bir e-posta yazılmalıdır.";
    }
  });
</script>

Bu örnekler HTML Önizleme aracına yapıştırılarak çalıştırılabilir.

Sık yapılan hatalar

  • Öğe henüz yüklenmeden seçilmeye çalışılırsa null döner ve "Cannot read properties of null" hatası görülür. Çözüm defer kullanmaktır.
  • id veya sınıf adındaki yazım hataları. Konsoldaki hata mesajı çoğunlukla sorunun nerede olduğunu gösterir.
  • = (atama) ile === (karşılaştırma) karıştırılması.
  • Tarayıcı geliştirici araçlarında Console sekmesi açıkken sayfanın hatalarının kontrol edilmemesi.

Sırada ne var?

  • Web depolama (localStorage): Bilgileri tarayıcıda saklayarak sayfa yenilendiğinde korumak.
  • fetch API: Başka bir kaynaktan veri çekmek.
  • Modüller ve çerçeveler: Daha büyük uygulamalar için kodu düzenleme yöntemleri.
  • Araçlar: Bu sitedeki Araçlar kategorisindeki uygulamalar, JavaScript ile yazılmış örneklerdir ve sayfa kaynağından incelenebilir.

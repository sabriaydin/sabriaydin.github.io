Linux’ta program kurmanın olağan yolu internetten .exe indirmek değil, dağıtımın paket yöneticisi ile resmî depolardan kurmaktır. Bu yöntem bağımlılıkları otomatik çözer, güncellemeleri tek yerden yönetir ve imzalı paketler sayesinde güvenlidir.

Paket ve depo kavramı

  • Paket: Programın dosyalarını, sürüm bilgisini ve bağımlılıklarını içeren arşiv (.deb, .rpm).
  • Depo (repository): Paketlerin tutulduğu, dağıtım tarafından işletilen sunucu.
  • Bağımlılık: Bir programın çalışmak için gerek duyduğu diğer paketler; yönetici bunları kendisi kurar.
  • Paket yöneticisi: Depoyu sorgulayan, kurulum/kaldırma yapan araç.

Sistemi güncellesudo apt upgradesudo dnf upgradesudo pacman -Syu
Kaldırsudo apt remove paketsudo dnf remove paketsudo pacman -R paket
Araapt search kelimednf search kelimepacman -Ss kelime

Arch’ta yalnızca -Sy ile liste güncellemek, ardından tek paket kurmak sistemi tutarsız bırakabilir; bunun yerine -Syu kullanılmalıdır.

apt ile günlük kullanım

sudo apt update                 # önce listeyi yenile
sudo apt upgrade                # kurulu paketleri güncelle
sudo apt full-upgrade           # gerekirse paket ekleyip çıkararak güncelle
sudo apt install vlc git curl   # birden çok paket
sudo apt remove vlc             # ayarlar kalır
sudo apt purge vlc              # ayarlarla birlikte kaldır
sudo apt autoremove             # artık gerekmeyen bağımlılıklar
apt search "metin editörü"
apt policy vlc                  # sürüm ve depo bilgisi

apt update yalnızca listeyi yeniler, program güncellemez; güncelleme için apt upgrade gerekir.

Elle indirilen paketler

BiçimKomut
.debsudo apt install ./paket.deb
.rpmsudo dnf install ./paket.rpm
Arch yerel paketsudo pacman -U paket.pkg.tar.zst

Elle indirilen paketler depo güvencesi taşımaz; yalnızca resmî kaynaklardan indirilmelidir.

Depo ekleme

Resmî depoda bulunmayan programlar için üretici depoları veya PPA kullanılabilir. Eklemeden önce güvenilirliği kontrol edilmelidir.

# Ubuntu PPA örneği
sudo add-apt-repository ppa:kullanici/depo
sudo apt update

# Depo listeleri
ls /etc/apt/sources.list.d/        # Debian ailesi
ls /etc/yum.repos.d/               # Red Hat ailesi

Evrensel paket biçimleri

Dağıtımdan bağımsız paketler, yeni sürüm programları herhangi bir dağıtıma kurmayı sağlar. Karşılığında disk alanı daha fazla harcanır.

AppImageTek dosya; kurulum gerektirmezchmod +x Uygulama.AppImage && ./Uygulama.AppImage

sudo snap remove vlc

Kaynak koddan derleme

Son çare olarak program kaynak kodundan derlenebilir. Bu, paket yöneticisinin takibi dışında kalır; güncelleme ve kaldırma elle yapılır.

sudo apt install build-essential        # derleme araçları
tar -xzf program-1.0.tar.gz && cd program-1.0
./configure
make
sudo make install                          # tercihen checkinstall ile paketlenir

Özet

  • Programlar resmî depolardan paket yöneticisiyle kurulur; bağımlılıklar otomatik çözülür.
  • Debian ailesinde apt, Red Hat ailesinde dnf, Arch’ta pacman kullanılır.
  • Önce liste güncellenir (apt update), sonra paketler yükseltilir.
  • Snap, Flatpak ve AppImage dağıtımdan bağımsız seçeneklerdir.
  • Yalnızca güvenilir depo ve paketler kullanılmalıdır.

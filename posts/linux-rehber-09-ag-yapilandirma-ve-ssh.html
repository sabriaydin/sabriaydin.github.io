Linux ağ üzerinde çalışan sistemlerde en yaygın kullanılan işletim sistemidir. Bu yazıda ağ durumunu görüntüleme, sorun giderme, dosya aktarma ve SSH ile uzaktaki bir sisteme güvenli bağlanma konuları anlatılmaktadır.

Ağ bilgisini görme

KomutAçıklama
ip a / ip -br aArayüzler ve IP adresleri (kısa biçim: -br)
ip rYönlendirme tablosu; varsayılan ağ geçidi
ip linkArayüz durumu (UP/DOWN)
hostname -IMakinenin IP adresleri
resolvectl statusDNS sunucuları
nmcli device statusNetworkManager arayüz durumu
curl ifconfig.meDış IP adresi

Eski ifconfig ve netstat komutları yerine ip ve ss önerilir.

Bağlantı testi

ping -c 4 8.8.8.8          # internet erişimi (IP ile)
ping -c 4 example.com      # DNS çözümü dâhil
traceroute example.com     # paket yolu
mtr example.com            # ping + traceroute, canlı
nc -zv sunucu 443          # port açık mı?
BelirtiOlası neden
IP’ye ping var, ada yokDNS sorunu
Hiçbirine ping yokAğ geçidi veya kablo / Wi-Fi sorunu
Ping var, site açılmıyorGüvenlik duvarı, proxy ya da hedef sorunu

DNS sorgulama

dig example.com             # ayrıntılı sorgu
dig +short example.com     # yalnızca cevap
dig MX example.com         # posta kaydı
nslookup example.com
host example.com
cat /etc/hosts             # yerel ad eşlemeleri

Port ve bağlantıları izleme

ss -tulpn                 # dinleyen portlar ve programlar (sudo ile süreç adı)
ss -tn                     # kurulu TCP bağlantıları
sudo lsof -i :80           # 80. portu kullanan program
ss seçeneğiAnlamı
-t / -uTCP / UDP
-lDinleyenler
-pSüreç bilgisi
-nSayısal gösterim (ad çözmeden)

Kablolu ve kablosuz ağ ayarı

Masaüstü dağıtımlarda ayarlar arayüzden yapılır; terminalden nmcli kullanılır.

nmcli device wifi list
nmcli device wifi connect "AgAdi" password "parola"
nmcli connection show
nmcli connection modify "Kablolu" ipv4.method manual ipv4.addresses 192.168.1.50/24 ipv4.gateway 192.168.1.1 ipv4.dns 1.1.1.1
nmcli connection up "Kablolu"

Ubuntu Server gibi sistemlerde ayar dosyası /etc/netplan/*.yaml içindedir ve sudo netplan apply ile uygulanır. Uzaktan bağlıyken ağ ayarını değiştirmek bağlantıyı kesebilir.

Dosya indirme: curl ve wget

wget https://example.com/dosya.zip              # indir
wget -c https://example.com/buyuk.iso            # kesilen indirmeye devam et
curl -O https://example.com/dosya.zip            # adını koruyarak indir
curl -I https://example.com                      # yalnızca başlık bilgisi
curl -s https://api.example.com/veri | head      # sessiz, çıktıyı yazdır

SSH ile uzaktan bağlanma

SSH (Secure Shell), uzaktaki bir sisteme şifreli bağlantıyla komut satırı erişimi sağlar. Varsayılan port 22’dir.

ssh kullanici@192.168.1.50
ssh -p 2222 kullanici@sunucu.example.com   # farklı port
ssh kullanici@sunucu "df -h"                # tek komut çalıştır
exit                                        # bağlantıyı kapat

Sunucu tarafında SSH hizmeti kurulu olmalıdır:

sudo apt install openssh-server
sudo systemctl enable --now ssh

SSH anahtarı ile parolasız ve güvenli giriş

Parola yerine anahtar çifti kullanmak daha güvenlidir. Özel anahtar sizde kalır, açık anahtar sunucuya konur.

ssh-keygen -t ed25519 -C "ayse@laptop"    # anahtar çifti üret
ssh-copy-id kullanici@sunucu              # açık anahtarı sunucuya kopyala
ssh kullanici@sunucu                      # artık parola sorulmaz

Özel anahtar (~/.ssh/id_ed25519) kimseyle paylaşılmamalı ve izni 600 olmalıdır. Kolaylık için ~/.ssh/config dosyası kullanılır:

Host sunucum
    HostName 192.168.1.50
    User kullanici
    Port 22
    IdentityFile ~/.ssh/id_ed25519
ssh sunucum           # artık bu kadar

Dosya aktarma: scp ve rsync

scp dosya.txt kullanici@sunucu:/home/kullanici/      # yükle
scp kullanici@sunucu:/var/log/syslog .                # indir
scp -r proje/ kullanici@sunucu:~/                     # dizin
rsync -avz --progress proje/ kullanici@sunucu:~/proje/ # sadece farkları aktarır
sftp kullanici@sunucu                                  # etkileşimli aktarım

SSH tüneli

ssh -L 8080:localhost:80 kullanici@sunucu    # yerel 8080 -> sunucudaki 80
ssh -D 1080 kullanici@sunucu                   # SOCKS vekil sunucu

Güvenlik duvarı (ufw)

Ubuntu’da basit güvenlik duvarı arayüzü ufw’dir (Fedora’da firewalld).

sudo ufw allow ssh               # SSH’ı önce izinle yoksa bağlantı kopar!
sudo ufw allow 80/tcp
sudo ufw enable
sudo ufw status verbose
sudo ufw delete allow 80/tcp

Uzak sunucuda ufw enable yapmadan önce SSH portuna izin verildiğinden emin olunmalıdır.

SSH güvenlik önerileri

  • Mümkünse parola ile girişi kapatın: /etc/ssh/sshd_config içinde PasswordAuthentication no.
  • Doğrudan root girişini kapatın: PermitRootLogin no.
  • Değişiklikten sonra: sudo systemctl restart ssh (başka bir oturumu açık tutarak test edin).
  • Sık deneme yapan adresleri engellemek için fail2ban kullanılabilir.

Özet

  • ip, ping, ss, dig ağ durumunu ve sorunları gösterir.
  • curl ve wget dosya indirir.
  • ssh uzak sisteme şifreli bağlanır; anahtar tabanlı giriş parolaya tercih edilir.
  • scp ve rsync dosya aktarır.
  • Güvenlik duvarında önce SSH’a izin verilmelidir.

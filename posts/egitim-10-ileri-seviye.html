Eğitimin son dersinde script'lerin sorunsuz çalışması için bilinmesi gereken ayrıntıları topluyoruz.

Gecikmeli değişken genişletme

Bir parantez bloğunun (for, if gövdesi) içindeki %değişken% ifadesi, blok çalışmaya başlamadan önce bir kez değerlendirilir. Bu yüzden aşağıdaki script her turda 0 yazar:

@echo off
set /a sayac=0
for %%i in (a b c) do (
    set /a sayac+=1
    echo Sayac: %sayac%
)
pause

Çözüm, değişkeni ! işaretleriyle yazıp gecikmeli genişletmeyi açmaktır. Bu şekilde değer satır çalışırken okunur:

@echo off
setlocal EnableDelayedExpansion
set /a sayac=0
for %%i in (a b c) do (
    set /a sayac+=1
    echo Sayac: !sayac!
)
pause

Kural: Parantez bloğunun içinde değeri değişen bir değişkeni !...! ile oku. Blok dışında %...% yeterlidir. Gecikmeli genişletme açıkken ! karakteri özel olur; dosya adlarında ! varsa kaybolabilir.

Metin parçalama ve değiştirme

@echo off
set "metin=Merhaba Dunya"
echo %metin:Dunya=Batch%
echo %metin:~0,7%
echo %metin:~-5%

setlocal EnableDelayedExpansion
set /a sayi=7
set "no=000!sayi!"
echo Sifir dolgulu: !no:~-3!
pause
  • %metin:eski=yeni% metindeki bir parçayı değiştirir (Merhaba Batch).
  • %metin:~0,7% baştan 7 karakter alır (Merhaba).
  • %metin:~-5% sondan 5 karakter alır (Dunya).
  • 000 ile birleştirip son 3 karakteri almak, sayılara sıfır dolgusu (007) eklemenin yaygın yoludur.

Özel karakterleri kaçırmak

&, |, <, >, ^ karakterleri komut satırında özel anlam taşır. Ekrana basmak istiyorsan önüne ^ koy. Yüzde işareti batch dosyasında %% olarak yazılır:

echo Ali ^& Veli
echo Sonuc ^> 10
echo 50%% indirim
echo Bos satir icin:
echo.

Parantez bloğunun içindeki bir yazıda kapanış parantezi varsa onu da ^) olarak yaz.

Boşluklu yollar ve start

Yolda boşluk varsa çift tırnak kullan. start komutu, tırnaklı ilk değeri pencere başlığı sayar; bu yüzden önüne boş bir başlık koymak gerekir:

start "" "C:\Program Files\Uygulama\uygulama.exe"

Türkçe karakterler

  1. Not Defteri'nde Dosya > Farklı Kaydet seç, Kodlama olarak UTF-8 seç.
  2. Scriptin ilk satırından sonra chcp 65001 >nul yaz.
  3. Başında gizli işaret (BOM) bulunan UTF-8 dosyalarda ilk satırda hata çıkabilir; güncel Windows 10 ve 11 sürümlerinde Not Defteri varsayılan olarak işaretsiz kaydeder.
@echo off
chcp 65001 >nul
echo Turkce karakterler: ğ ü ş ı ö ç İ
pause

Harfler hâlâ bozuk görünürse pencere başlığına sağ tıkla, Özellikler > Yazı Tipi bölümünden Consolas'ı seç. Sorun sürerse mesajlarda Türkçe karakter kullanmadan yaz. goto etiketlerinde (:menu gibi) Türkçe karakter kullanma.

Yönetici yetkisi kontrolü

Sistem klasörlerine yazan veya servisleri değiştiren script'ler yönetici yetkisi ister. Başta kontrol edip kullanıcıyı uyarabilirsin:

@echo off
fltmc >nul 2>&1
if errorlevel 1 (
    echo Bu script yonetici olarak calistirilmali.
    echo Dosyaya sag tiklayip "Yonetici olarak calistir" secin.
    pause
    exit /b 1
)
echo Yonetici yetkisi var.
pause

İstersen script kendini yönetici olarak yeniden de başlatabilir. Windows bir onay penceresi gösterir:

@echo off
fltmc >nul 2>&1 || (
    powershell -NoProfile -Command "Start-Process -FilePath '%~f0' -Verb RunAs"
    exit /b
)
echo Yonetici olarak calisiyor.
pause

Bölgesel ayardan bağımsız tarih

%date% değişkeninin biçimi bilgisayarın bölgesel ayarına göre değişir. Dosya adında kullanılacak tarih için PowerShell ile sabit bir biçim almak daha güvenlidir:

@echo off
for /f %%t in ('powershell -NoProfile -Command "Get-Date -Format yyyy-MM-dd_HH-mm"') do set "zaman=%%t"
echo Zaman damgasi: %zaman%
pause

Eğitimi tamamladın. Şimdi öğrendiklerini gerçek işlerde kullanabileceğin örnek programlara geçebilirsin; ilk durak Otomatik Yedekleme Aracı.

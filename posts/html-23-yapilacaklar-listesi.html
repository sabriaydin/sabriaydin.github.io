İçeriğe geç

Bu yazıda önceki bölümlerde anlatılan HTML, CSS ve JavaScript bilgileri tek bir küçük uygulamada birleştirilir: görev eklenebilen, tamamlandı olarak işaretlenebilen, silinebilen ve sayfa kapatılıp açıldığında da korunan bir yapılacaklar listesi. Uygulama tek bir .html dosyasından oluşur ve herhangi bir kurulum gerektirmez.

Uygulamanın özellikleri

  • Forma yazılan görev listeye eklenir (Enter veya Ekle düğmesiyle).
  • Her görevin bir onay kutusu vardır; işaretlenince üstü çizilir.
  • Sil düğmesi görevi kaldırır.
  • Kalan görev sayısı gösterilir.
  • Veriler tarayıcının localStorage alanında saklanır; sayfa yenilense veya kapatılsa da kaybolmaz.
  • Etiketler, aria-label ve aria-live ile klavye ve ekran okuyucu desteği vardır.

Tam kod

Aşağıdaki kod bir metin düzenleyicisine yapıştırılıp yapilacaklar.html adıyla kaydedilir ve tarayıcıda açılır. Alternatif olarak HTML Önizleme aracına yapıştırılarak denenebilir (araç, sayfa içinde çalıştığı için localStorage kalıcılığı bu yöntemde çalışmayabilir).

<!DOCTYPE html>
<html lang="tr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Yapılacaklar</title>
  <style>
    * { box-sizing: border-box; }
    .sr { position: absolute; left: -999px; }
    body { font-family: system-ui, sans-serif; background: #f3f1ed; color: #222; margin: 0; }
    main { max-width: 480px; margin: 2rem auto; padding: 0 1rem; }
    form { display: flex; gap: 0.5rem; }
    input[type="text"] { flex: 1; padding: 0.6rem; font-size: 1rem; }
    button { padding: 0.6rem 1rem; font-size: 1rem; cursor: pointer; }
    ul { list-style: none; padding: 0; }
    li { display: flex; align-items: center; gap: 0.5rem; padding: 0.6rem 0; border-bottom: 1px solid #ccc; }
    li label { flex: 1; }
    li.bitti label { text-decoration: line-through; color: #777; }
  </style>
</head>
<body>
  <main>
    <h1>Yapılacaklar</h1>
    <form id="form">
      <label for="yeni" class="sr">Yeni görev</label>
      <input type="text" id="yeni" placeholder="Yeni görev yazın" required>
      <button type="submit">Ekle</button>
    </form>
    <ul id="liste"></ul>
    <p id="ozet" aria-live="polite"></p>
  </main>

  <script>
    const form = document.getElementById("form");
    const yeni = document.getElementById("yeni");
    const liste = document.getElementById("liste");
    const ozet = document.getElementById("ozet");

    // Kayıtlı görevleri oku (bozuk veri varsa boş liste kullan)
    let gorevler = [];
    try {
      gorevler = JSON.parse(localStorage.getItem("gorevler")) || [];
    } catch (hata) {
      gorevler = [];
    }

    function kaydet() {
      localStorage.setItem("gorevler", JSON.stringify(gorevler));
    }

    function ciz() {
      liste.textContent = "";
      gorevler.forEach((gorev, sira) => {
        const li = document.createElement("li");
        if (gorev.bitti) li.className = "bitti";

        const kutu = document.createElement("input");
        kutu.type = "checkbox";
        kutu.id = "g" + sira;
        kutu.checked = gorev.bitti;
        kutu.addEventListener("change", () => {
          gorev.bitti = kutu.checked;
          kaydet();
          ciz();
        });

        const etiket = document.createElement("label");
        etiket.htmlFor = kutu.id;
        etiket.textContent = gorev.metin;

        const sil = document.createElement("button");
        sil.type = "button";
        sil.textContent = "Sil";
        sil.setAttribute("aria-label", gorev.metin + " görevini sil");
        sil.addEventListener("click", () => {
          gorevler.splice(sira, 1);
          kaydet();
          ciz();
        });

        li.append(kutu, etiket, sil);
        liste.append(li);
      });

      const kalan = gorevler.filter((g) => !g.bitti).length;
      ozet.textContent = gorevler.length
        ? kalan + " görev kaldı (toplam " + gorevler.length + ")"
        : "Henüz görev yok.";
    }

    form.addEventListener("submit", (olay) => {
      olay.preventDefault();
      const metin = yeni.value.trim();
      if (!metin) return;
      gorevler.push({ metin: metin, bitti: false });
      yeni.value = "";
      kaydet();
      ciz();
    });

    ciz();
  </script>
</body>
</html>

Kodun açıklaması

1. HTML yapısı

Sayfada üç ana parça vardır: görev yazma formu, görevlerin gösterildiği boş bir ul listesi ve kalan görev sayısını gösteren bir p. Liste öğeleri HTML'de yazılmaz; JavaScript tarafından üretilir. label öğesine sr (yalnızca ekran okuyucu) sınıfı verilmiştir; görünmez ancak ekran okuyucu tarafından okunur (bkz. Erişilebilirlik).

2. Veriyi tutma: gorevler dizisi

Tüm görevler bir dizide tutulur ve her görev bir nesnedir: { metin: "Ekmek al", bitti: false }. Sayfa her güncellendiğinde ekran bu diziye bakılarak yeniden çizilir. Bu yaklaşım, veriyi ekrandan ayrı tutmanın en basit örneğidir: önce dizi değişir, sonra ekran dizinin durumuna göre çizilir.

3. localStorage ile kayıt

  • localStorage yalnızca metin saklar. Dizi, JSON.stringify() ile metne çevrilerek kaydedilir.
  • Okurken JSON.parse() ile tekrar diziye çevrilir.
  • Kayıtlı veri yoksa getItem null döndürür; || [] ile boş dizi kullanılır.
  • try ... catch, kayıtlı verinin bozuk olması halinde uygulamanın çökmesini önler.

4. ciz() fonksiyonu

ciz() önce listeyi temizler (liste.textContent = ""), sonra her görev için li, onay kutusu, label ve Sil düğmesini oluşturup listeye ekler. Görev metni textContent ile yazıldığı için kullanıcının girdiği <b>x</b> gibi ifadeler HTML olarak yorumlanmaz, düz metin olarak gösterilir. Bu, XSS saldırılarına karşı temel korumadır; innerHTML bu nedenle kullanılmamıştır.

5. Olaylar

OlayYapılan işlem
Formun submit olayıpreventDefault() ile sayfanın yeniden yüklenmesi engellenir; metin boş değilse diziye eklenir, kaydedilir ve liste yeniden çizilir.
Onay kutusunun change olayıGörevin bitti değeri güncellenir, kaydedilir, liste yeniden çizilir.
Sil düğmesinin click olayısplice(sira, 1) ile görev diziden çıkarılır, kaydedilir, liste yeniden çizilir.

Her değişiklikten sonra aynı üç adım uygulanır: diziyi değiştir → kaydet → yeniden çiz. Bu düzen, uygulama büyüdüğünde de kodun anlaşılır kalmasını sağlar.

Çalışmayı kontrol etme

  1. Birkaç görev ekleyip sayfayı yenileyin: görevler yerinde kalmalıdır.
  2. F12 ile geliştirici araçlarını açıp Application > Local Storage bölümünde gorevler anahtarının değerini görün (bkz. Geliştirici Araçları).
  3. Görev metnine <b>deneme</b> yazın: metin kalın yazı olarak değil, olduğu gibi görünmelidir.

Geliştirme fikirleri

  • Filtreleme: Tümü / Yapılacaklar / Tamamlananlar düğmeleri ekleme.
  • Düzenleme: Görev metnine çift tıklayınca değiştirebilme.
  • Tamamlananları temizle: Bitmiş görevleri tek tıkla silme (gorevler.filter(g => !g.bitti)).
  • Son tarih ve öncelik: Göreve tarih ve oncelik alanları ekleyip sıralama.
  • Dışa aktarma: Verileri .json dosyası olarak indirme.

localStorage hakkında bilinmesi gerekenler

  • Veriler yalnızca o tarayıcıda ve o cihazda saklanır; başka cihazlarla eşitlenmez.
  • Tarayıcı verileri temizlendiğinde (özellikle gizli pencerede veya "site verilerini sil" işleminde) kaybolur.
  • Kapasite yaklaşık 5 MB ile sınırlıdır.
  • Parola gibi hassas veriler localStorage içinde saklanmamalıdır; sayfadaki herhangi bir betik bu verilere erişebilir.

İçeriğe geç

Git, dosya değişikliklerini takip eden ücretsiz ve açık kaynaklı bir sürüm kontrol sistemidir. Yazılım projelerinde kodun geçmişini saklamak, farklı sürümlere dönmek ve ekip çalışması yapmak için kullanılır. GitHub gibi hizmetlerin temelinde de Git bulunur.

Ne işe yarar?

  • Dosya değişikliklerinin geçmişini saklar.
  • Dallar (branch) ile paralel çalışmayı sağlar.
  • Çevrimdışı çalışabilir.
  • GitHub, GitLab gibi hizmetlerle birlikte kullanılır.

Desteklenen platformlar

Windows, macOS ve Linux.

Kurulum

  1. İşletim sistemine uygun kurulum paketini indir.
  2. Windows kurulumunda varsayılan seçeneklerle devam et.
  3. Terminalde git --version komutu ile kurulumu doğrula.

Güvenli indirme ve notlar

  • Git, komut satırı tabanlıdır; grafik arayüz için ayrı istemciler bulunur.
  • Linux'ta çoğu dağıtımın paket yöneticisi ile kurulur (örneğin Debian ve Ubuntu için sudo apt install git).
  • Programı yalnızca git-scm.com adresinden veya işletim sisteminin resmi paket yöneticisinden edinmek gerekir.
Bağlantılar yazının hazırlandığı tarihte geçerliydi. Sürüm numarası ve indirme seçenekleri zamanla değişebilir; güncel bilgiler için resmi sayfaya bakılmalıdır.

İçeriğe geç

Değişken, bir değere verdiğin isimdir. Batch'te set komutuyla oluşturulur ve değeri % işaretleri arasında yazarak kullanılır.

Değişken tanımlama ve kullanma

@echo off
set ad=Sabri
echo Merhaba %ad%
pause

set ad=Sabri satırında eşittirin etrafına boşluk koyma. set ad = Sabri yazarsan değişkenin adı ad (sonunda boşlukla) olur ve %ad% boş gelir. Değerin sonuna yanlışlıkla boşluk girmesini önlemek için en güvenli yazım tırnaklıdır:

set "ad=Sabri"

Değişken adlarında büyük/küçük harf fark etmez: %AD% ile %ad% aynı değişkendir.

Kullanıcıdan bilgi alma

set /p kullanıcıya soru sorar ve yazdığı cevabı değişkene koyar.

@echo off
set /p "ad=Adin nedir? "
echo Merhaba %ad%, tanistigimiza memnun oldum.
pause

Matematik işlemleri

set /a sayısal işlem yapar. Yalnızca tam sayılarla çalışır; ondalık sonuç vermez (10/3 sonucu 3 olur).

@echo off
set /a toplam=5+3
set /a carpim=4*6
set /a bolum=10/3
set /a kalan=10%%3
echo Toplam: %toplam%
echo Carpim: %carpim%
echo Bolum: %bolum%
echo Kalan: %kalan%

set /a sayac=1
set /a sayac+=1
echo Sayac: %sayac%
pause

Kalan (mod) işleminde batch dosyasının içinde %% yazılır; doğrudan komut satırında tek % yeterlidir. +=, -=, *= ve /= kısaltmaları da çalışır.

Hazır sistem değişkenleri

DeğişkenNe verir
%username%Windows kullanıcı adı
%computername%Bilgisayar adı
%userprofile%Kullanıcı klasörü (örn. C:\Users\Ad)
%temp%Geçici dosyalar klasörü
%cd%Şu anda içinde bulunulan klasör
%date% ve %time%Tarih ve saat (biçimi bölgesel ayara göre değişir)
%random%0 ile 32767 arasında rastgele sayı
 
@echo off
echo Kullanici: %username%
echo Bilgisayar: %computername%
echo Klasor: %cd%
set /a zar=%random% %% 6 + 1
echo Zar: %zar%
pause

Değişkeni silme ve listeleme

set ad=
set

set ad= değişkeni siler. Parametresiz set tüm değişkenleri listeler; set a yazarsan adı a ile başlayanları gösterir.

setlocal ile değişkenleri sınırlamak

Normalde bir script içinde tanımladığın değişkenler script bittikten sonra da komut penceresinde kalır. Bunu istemiyorsan dosyanın başına setlocal, sonuna endlocal yaz. Böylece değişkenler yalnızca bu script içinde yaşar.

@echo off
setlocal
set "gecici=Bu sadece bu scriptte var"
echo %gecici%
endlocal
pause

Bir sonraki derste bu değişkenleri if ile karşılaştırıp kararlar vereceğiz.

Batch Uygulamaları

Gerçek bir programlama dilinden alınmış gibi görünen rastgele kod parçacıklarını ekrana döken batch programı.

İçindekiler
  1. Nasıl kullanılır?
  2. Kod nasıl çalışıyor?
  3. Özelleştirme

Bu program, hazır kod parçacıklarından oluşan bir listeden rastgele satırlar seçerek ekrana sürekli akan bir "kod" görünümü oluşturur.

Önemli: Bu program tamamen görsel bir gösteridir; hiçbir dosyayı silmez, hiçbir ayarı değiştirmez ve internete bağlanmaz. Yalnızca ekran yazısını, rengini ve bir pencere başlığını değiştirir; pencereyi kapattığınızda bilgisayarınızda hiçbir iz kalmaz. Şaka amaçlı kullanırken karşındaki kişiyi gerçekten korkutmamaya dikkat et.

Nasıl kullanılır?

  1. Aşağıdaki kodu Not Defteri'ne yapıştırın ve program-27-akan-kod-arka-plani.bat adıyla kaydedin (Kayıt türü: Tüm dosyalar).
  2. Çift tıklayarak çalıştırın. Kapatmak için pencereyi normal şekilde kapatın veya Ctrl+C kullanın.
@echo off
title Derleniyor
color 0a
cls
set s1=function baglan(sunucu) {
set s2=  if (yetki == true) return erisim;
set s3=}
set s4=class Sistem extends Ag {
set s5=  veri = sifrele(paket);
set s6=  return veri.gonder();
set s7=const anahtar = uret_rsa(2048);
set s8=while (bagli) { dinle(port); }
:dongu
set /a "n=%random% %% 8 + 1"
call echo %%s%n%%%
timeout /t 0 >nul
goto dongu

Kod nasıl çalışıyor?

Sekiz adet sabit kod satırı önceden değişkenlere yazılır (s1'den s8'e kadar); döngü her seferinde rastgele birini seçip ekrana basar. call echo %%s%n%%% satırı, değişken adının içine bir değişken daha gömülmesini sağlayan bir batch tekniğidir.

Özelleştirme

Kodun başındaki AYARLAR bölümündeki (varsa) değerleri değiştirerek metni, rengi veya hızı kendinize göre ayarlayabilirsiniz. color 0a komutundaki ilk rakam zemin, ikinci rakam yazı rengidir (0: siyah, a: açık yeşil, b: açık camgöbeği, c: açık kırmızı, e: sarı, f: beyaz).

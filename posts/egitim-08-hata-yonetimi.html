İçeriğe geç

Bir komut başarısız olsa da script çalışmaya devam eder. Kontrol etmezsen dosya kopyalanmamışken "Tamamlandı" yazabilir. Bu derste hataları yakalamayı ve yapılanları kayıt altına almayı öğreniyorsun.

Çıkış kodu: errorlevel

Her komut bittiğinde bir sayı bırakır: 0 başarı, 0 dışındaki değerler hata demektir (çoğu zaman 1). %errorlevel% ile okunur:

@echo off
ping -n 1 192.168.255.254 >nul
echo Cikis kodu: %errorlevel%
pause

%errorlevel% bir sonraki komutta değişir. Daha sonra kullanacaksan hemen bir değişkene ata: set "kod=%errorlevel%".

&& ve || operatörleri

komut1 && komut2 yazarsan komut2 yalnızca komut1 başarılıysa çalışır. komut1 || komut2 ise yalnızca komut1 başarısızsa çalışır.

md "D:\Yedek" && echo Klasor olusturuldu
copy a.txt "D:\Yedek\" >nul && echo Tamam || echo Hata

Dikkat: A && B || C yapısında B başarısız olursa C de çalışır. Küçük kontroller için pratiktir; önemli işlerde if errorlevel daha açıktır.

Log dosyası tutmak

Script'in ne yaptığını bir dosyaya yazdırırsan sorun çıktığında nedenini görebilirsin. Aşağıdaki script, her satırı tarih ve saatle log'a ekleyen küçük bir alt program kullanır:

@echo off
set "LOG=%~dp0islem.log"

call :yaz "Script basladi"
copy "C:\Belgeler\rapor.docx" "D:\Yedek\" >nul 2>&1
if errorlevel 1 (
    call :yaz "HATA: rapor.docx kopyalanamadi"
    exit /b 1
)
call :yaz "rapor.docx kopyalandi"
call :yaz "Script bitti"
exit /b 0

:yaz
(echo [%date% %time%] %~1) >> "%LOG%"
echo %~1
exit /b

(echo ...) >> "%LOG%" biçiminde parantez kullanmak, mesaj bir rakamla bittiğinde yönlendirmenin yanlış yorumlanmasını önler.

robocopy çıkış kodları

robocopy "C:\Belgeler" "D:\Yedek" /e /r:2 /w:2

Script'ten çıkış kodu döndürmek

exit /b 0 başarıyla, exit /b 1 hatayla çıkış demektir. Bu script'i başka bir batch dosyası call ile çağırdıysa kodu %errorlevel% ile okuyabilir. /b yazmazsan komut penceresinin tamamı kapanır; script'lerde her zaman exit /b kullan.

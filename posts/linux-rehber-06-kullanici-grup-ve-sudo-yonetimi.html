Linux’ta her işlem bir kullanıcı kimliğiyle çalışır. Günlük işler normal kullanıcıyla, sistem yönetimi ise gerektiğinde geçici olarak yönetici (root) yetkisiyle yapılır. Bu yazıda kullanıcı hesapları, gruplar ve sudo mekanizması anlatılmaktadır.

Kullanıcı türleri

TürUIDAçıklama
root0Sınırsız yetkili yönetici; doğrudan oturum açmak önerilmez
Sistem kullanıcıları1–999Hizmetlerin (web sunucusu, veri tabanı) kullandığı hesaplar; oturum açılmaz

id ayse           # başka kullanıcı

last | head       # son girişler
groups            # üyesi olduğum gruplar

Kullanıcı ekleme ve silme

Debian ailesinde adduser soru soran, kolay bir araçtır. useradd ise tüm dağıtımlarda bulunan alt düzey komuttur.

sudo adduser mehmet                       # etkileşimli (Debian/Ubuntu)
sudo useradd -m -s /bin/bash mehmet       # -m ev dizini, -s kabuk
sudo passwd mehmet                        # parola belirle
sudo userdel mehmet                       # sil (ev dizini kalır)
sudo userdel -r mehmet                    # ev dizini ile birlikte sil

Silme işlemi geri alınamaz; önemli veriler önceden yedeklenmelidir.

Kullanıcıyı değiştirme: usermod

KomutAçıklama
sudo usermod -aG sudo mehmetKullanıcıyı gruba ekler (-a unutulursa diğer gruplardan çıkar!)
sudo usermod -s /bin/zsh mehmetKabuğu değiştirir
sudo usermod -L mehmetHesabı kilitler
sudo usermod -U mehmetKilidi açar
sudo usermod -l yeniad eskiadKullanıcı adını değiştirir
chsh -s /bin/zshKendi varsayılan kabuğunu değiştirir

Grup yönetimi

sudo groupadd proje                # grup oluştur
sudo usermod -aG proje ayse         # üye ekle
sudo gpasswd -d ayse proje          # üyelikten çıkar
sudo groupdel proje                 # grubu sil
getent group proje                  # üyeleri göster
newgrp proje                        # oturumu yeniden açmadan grubu etkinleştir

Grup üyeliği değişikliği, kullanıcı oturumu kapatıp yeniden açana kadar geçerli olmaz.

Parola işlemleri

passwd                   # kendi parolanı değiştir
sudo passwd mehmet       # başkasının parolası
sudo passwd -l mehmet    # parolayı kilitle
sudo chage -l mehmet     # parola süresi bilgisi
sudo chage -M 90 mehmet  # 90 günde bir değiştirme zorunluluğu

Parola yazarken ekranda hiçbir şey görünmez; bu normaldir.

sudo: geçici yönetici yetkisi

sudo, tek bir komutu root yetkisiyle çalıştırır. Kullanıcı kendi parolasını girer; ayrıca işlem günlüğe kaydedilir. Bu nedenle sürekli root hesabıyla çalışmaktan daha güvenlidir.

sudo apt update           # tek komut
sudo -i                   # root kabuğu aç (dikkatli kullanılmalı)
sudo -u mehmet komut      # başka kullanıcı olarak çalıştır
sudo -l                   # hangi komutlara yetkim var?
sudo !!                   # son komutu sudo ile tekrarla

sudoers dosyasını düzenleme

Yetkiler /etc/sudoers dosyasında tanımlanır. Bu dosya hatalıysa sudo çalışmaz; bu yüzden doğrudan değil, visudo ile düzenlenir. Sözdizimi denetlenir.

sudo visudo

# Örnek satırlar
%sudo   ALL=(ALL:ALL) ALL                     # sudo grubundakiler her şeyi yapabilir
mehmet ALL=(ALL) /usr/bin/apt                 # yalnızca apt
ayse   ALL=(ALL) NOPASSWD: /sbin/reboot       # parola sormadan yeniden başlat

Ayrı yapılandırmalar için /etc/sudoers.d/ altına dosya eklenebilir (sudo visudo -f /etc/sudoers.d/mehmet).

Kullanıcı değiştirme

su - mehmet            # mehmet olarak oturum (parolasını sorar)
su -                   # root (root parolası gerekir)
exit                   # önceki kullanıcıya dön

Güvenlik önerileri

  • Günlük çalışma için normal kullanıcı kullanın; yönetici işlemlerinde sudo tercih edin.
  • Kullanılmayan hesapları kilitleyin veya silin.
  • Güçlü, benzersiz parolalar kullanın; sunucularda SSH anahtarı tercih edin.
  • NOPASSWD kuralını yalnızca gerekli ve sınırlı komutlar için verin.
  • Kimin sudo yetkisi olduğunu düzenli kontrol edin: getent group sudo

Özet

  • Kullanıcılar /etc/passwd, gruplar /etc/group dosyasında tutulur.
  • adduser/useradd, usermod, userdel hesap yönetimini sağlar.
  • usermod -aG ile gruba eklerken -a unutulmamalıdır.
  • sudo yetkisi sudo veya wheel grubuyla verilir; ayarlar visudo ile düzenlenir.

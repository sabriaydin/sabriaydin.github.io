İçeriğe geç

Kısayollar fareye gitmeden işleri hızlandırır.

Temel kısayollar

  • Ctrl + C / X / V: Kopyala / Kes / Yapıştır
  • Ctrl + Z / Y: Geri al / Yinele
  • Ctrl + A: Tümünü seç
  • Ctrl + S: Kaydet
  • Ctrl + F: Bul
  • Ctrl + P: Yazdır
  • Alt + Tab: Açık pencereler arasında geçiş
  • Alt + F4: Pencereyi kapat

Windows tuşu kısayolları

  • Win + D: Masaüstünü göster
  • Win + E: Dosya Gezgini
  • Win + L: Bilgisayarı kilitle
  • Win + I: Ayarlar
  • Win + V: Pano geçmişi
  • Win + . (nokta): Emoji paneli
  • Win + Tab: Görev görünümü
  • Win + Ok tuşları: Pencereyi ekranın yarısına veya köşesine yasla
  • Win + Shift + S: Ekran alıntısı
  • Win + X: Gelişmiş kullanıcı menüsü
  • Win + R: Çalıştır penceresi

Dosya ve sistem

  • Ctrl + Shift + Esc: Görev Yöneticisi
  • F2: Seçili dosyayı yeniden adlandır
  • Shift + Delete: Dosyayı kutuya atmadan kalıcı sil
  • Ctrl + Shift + N: Yeni klasör
  • Ctrl + Shift + T: Tarayıcıda kapatılan sekmeyi geri aç

Sanal masaüstleri (Windows 10/11)

  • Win + Ctrl + D: Yeni masaüstü
  • Win + Ctrl + Sol/Sağ ok: Masaüstleri arası geçiş

Batch Rehberi

Batch'te alt metin alma, bulma ve değiştirme, uzunluk bulma, boşluk temizleme, büyük harfe çevirme, metin içinde arama ve for /f ile parçalama.

İçindekiler
  1. Alt metin alma: %değişken:~başlangıç,uzunluk%
  2. Bulma ve değiştirme: %değişken:eski=yeni%
  3. Metnin uzunluğunu bulma
  4. Baştaki ve sondaki boşlukları temizleme
  5. Büyük harfe çevirme
  6. Metnin içinde arama
  7. Metni parçalama: for /f
  8. Rastgele metin ve birleştirme
  9. Özet

Batch dilinde ayrı bir "metin türü" ve hazır metin fonksiyonları yoktur; ancak değişken genişletme sözdizimi, alt metin alma ve değiştirme gibi temel işleri yapabilir. Bu yazıdaki işlemler %DEGISKEN:...% biçimindeki özel sözdizimine dayanır. Gecikmeli genişletmeyle ilgili ayrıntılar için İleri Seviye yazısına bakılabilir.

Alt metin alma: %değişken:~başlangıç,uzunluk%

@echo off
set "METIN=Merhaba Dunya"
echo %METIN:~0,7%      rem Merhaba   (0. karakterden 7 karakter)
echo %METIN:~8%        rem Dunya     (8. karakterden sona kadar)
echo %METIN:~-5%       rem Dunya     (sondan 5 karakter)
echo %METIN:~0,-6%     rem Merhaba   (sondaki 6 karakter atilir)
pause
BiçimAnlamı
%X:~n%n. karakterden sona kadar (sayım 0'dan başlar)
%X:~n,m%n. karakterden başlayarak m karakter
%X:~-n%Sondan n karakter
%X:~0,-n%Sondaki n karakter atılır
Bu yöntem yalnızca yüzde işaretleri arasında çalışır; for döngü değişkenleri (%%i) için önce set ile bir değişkene aktarılması gerekir.

Bulma ve değiştirme: %değişken:eski=yeni%

@echo off
set "YOL=C:\Belgeler\Rapor Final.docx"
echo %YOL: =_%                rem bosluklar alt cizgi olur
echo %YOL:Final=Taslak%       rem Final yerine Taslak yazilir
echo %YOL:\=/%                rem ters bolu yerine bolu isareti
echo %YOL:.docx=%             rem .docx silinir (yeni metin bos)
pause
  • Değiştirme büyük/küçük harf ayrımı yapmaz: %X:abc=1% hem abc hem ABC ifadelerini değiştirir.
  • Aranan metin = işareti içeremez.
  • Aranan metin * ile başlarsa, baştan ilk eşleşmeye kadar olan bölüm silinir: %X:*\=% ilk ters bölüye kadar olan kısmı atar.
set "DOSYA=a_b_c.txt"
echo %DOSYA:*_=%      rem b_c.txt  (ilk alt cizgiye kadar silinir)

Metnin uzunluğunu bulma

Batch'te uzunluğu veren bir fonksiyon yoktur; metin her seferinde bir karakter kısaltılarak sayılır:

@echo off
call :uzunluk "Merhaba Dunya"
echo Uzunluk: %UZN%
pause
exit /b

:uzunluk
rem %1 = metin, sonuc UZN degiskenine yazilir
set "S=%~1"
set /a UZN=0
:uzunluk_dongu
if not defined S exit /b
set "S=%S:~1%"
set /a UZN+=1
goto :uzunluk_dongu

Örnekte metin boş değilken ilk karakter atılır ve sayaç artırılır. Metin tükendiğinde if not defined S koşulu alt programı sonlandırır.

Baştaki ve sondaki boşlukları temizleme

@echo off
set "S=     orta bosluklu metin   "

rem Bastaki bosluklar: for /f bunlari otomatik atar
for /f "tokens=* delims= " %%a in ("%S%") do set "S=%%a"

rem Sondaki bosluklar: dongu ile birer birer silinir
:sondaki
if not defined S goto :tamam
if not "%S:~-1%"==" " goto :tamam
set "S=%S:~0,-1%"
goto :sondaki
:tamam
echo [%S%]
pause

Büyük harfe çevirme

Yerleşik bir komut yoktur. Alfabenin her harfi için değiştirme yapılarak (yalnızca İngilizce harfler için) şu klasik yöntem kullanılır:

@echo off
set "S=merhaba dunya"
for %%a in ("a=A" "b=B" "c=C" "d=D" "e=E" "f=F" "g=G" "h=H" "i=I" "j=J" "k=K" "l=L" "m=M" "n=N" "o=O" "p=P" "q=Q" "r=R" "s=S" "t=T" "u=U" "v=V" "w=W" "x=X" "y=Y" "z=Z") do call set "S=%%S:%%~a%%"
echo %S%
pause

Türkçe karakterleri (ı, i, ş vb.) doğru dönüştürmek için PowerShell kullanılabilir: powershell -NoProfile -Command "'merhaba'.ToUpper([Globalization.CultureInfo]'tr-TR')" (bkz. PowerShell ve Yardımcı Araçlar).

Metnin içinde arama

@echo off
set "ADRES=https://example.com/sayfa"

rem Yontem 1: degistirme ile
if not "%ADRES:https=%"=="%ADRES%" echo Adres https iceriyor

rem Yontem 2: findstr ile
echo %ADRES%| findstr /i "example" > nul && echo example geciyor

rem Basinda mi?
if /i "%ADRES:~0,5%"=="https" echo Adres https ile basliyor
pause

İlk yöntemde, aranan ifade silinmiş metnin orijinalden farklı olması metnin içinde bulunduğunu gösterir.

Metni parçalama: for /f

@echo off
set "KAYIT=Ali,35,Ankara"
for /f "tokens=1,2,3 delims=," %%a in ("%KAYIT%") do (
    echo Ad    : %%a
    echo Yas   : %%b
    echo Sehir : %%c
)

rem tum parcalar tek degiskende: tokens=2* ikinci parca ve geri kalan
for /f "tokens=1,* delims= " %%a in ("birinci ikinci ucuncu") do echo %%a / %%b
pause
  • tokens=1,2,3 ilk üç parçayı %%a, %%b, %%c değişkenlerine verir (değişken adları alfabetik sırayla devam eder).
  • tokens=1,* ilk parçayı ve geri kalan metnin tamamını ayrı değişkenlere verir.
  • delims= ayırıcı karakterleri belirler. Boşluk ayırıcı olarak yazılacaksa delims= sonrasına bir boşluk konur.

Rastgele metin ve birleştirme

set "AD=dosya"
set "UZANTI=txt"
set "TAMAD=%AD%_%RANDOM%.%UZANTI%"
echo %TAMAD%

Metinleri birleştirmek için özel bir işleç yoktur; değişkenler ve sabit metinler yan yana yazılır.

Özet

  • Alt metin: %X:~n,m%; değiştirme: %X:eski=yeni%.
  • Uzunluk bulma, boşluk temizleme ve büyük harfe çevirme için küçük alt programlar yazılır.
  • Metin içinde arama için değiştirme karşılaştırması veya findstr kullanılır.
  • Karmaşık metin işlerinde (Türkçe karakter, düzenli ifade) PowerShell yardımcı olarak çağrılabilir.

İçeriğe geç

Ev veya ofis ağında kimlerin bağlı olduğunu bilmek, ağ güvenliğinin ilk adımıdır. Tanınmayan bir cihaz, komşunun kullandığı bir Wi-Fi bağlantısına veya ele geçirilmiş bir cihaza işaret edebilir. Bu uygulama, bilgisayarın bağlı olduğu yerel ağın (örneğin 192.168.1.1 - 192.168.1.254) tamamını tarar ve yanıt veren cihazları listeler.

Ne yapar?

  • Etkin ağ bağlantısının IP adresini bulur ve taranacak aralığı otomatik belirler.
  • Aralıktaki 254 adrese birer ping gönderir; yanıt verenleri canlı cihaz olarak listeler.
  • Sonuçları ARP tablosuyla birleştirip IP adresi ve fiziksel (MAC) adres eşleşmelerini gösterir.
  • Canlı cihaz listesini geçici bir dosyaya kaydeder.

Nasıl kullanılır?

  1. Kod Not Defteri'ne yapıştırılır ve ag_radari.bat adıyla kaydedilir (Kayıt türü: Tüm dosyalar seçilmelidir; aksi halde dosya .txt olarak kaydedilir).
  2. Dosyaya çift tıklanarak çalıştırılır.
  3. Başlangıçtaki izin sorusuna E ile cevap verilir. Tarama 1-2 dakika sürer; pencere başlığında taranan adres görülür.
@echo off
setlocal EnableExtensions
title [ NETWORK RADAR ] Yerel Ag Cihaz Tarayicisi
color 0A
cls
echo.
echo   ====================================================
echo    [ NETWORK RADAR ]  Yerel Ag Cihaz Tarayicisi
echo   ====================================================
echo.
echo [!] Bu arac yalnizca SAHIBI OLDUGUNUZ veya yazili izniniz bulunan
echo     aglarda kullanilmalidir. Yabanci aglarin taranmasi suctur.
echo.
choice /c EH /n /m "Devam edilsin mi? [E/H]: "
if errorlevel 2 exit /b 0
echo.

set "IP="
for /f "delims=" %%i in ('powershell -NoProfile -Command "(Get-NetIPConfiguration | Where-Object { $_.IPv4DefaultGateway -ne $null } | Select-Object -First 1).IPv4Address.IPAddress" 2^>nul') do set "IP=%%i"
if not defined IP goto :ag_yok

for /f "tokens=1-3 delims=." %%a in ("%IP%") do set "AG=%%a.%%b.%%c"
echo [+] Yerel adres      : %IP%
echo [+] Taranan aralik   : %AG%.1 - %AG%.254
echo.
echo [*] Tarama basladi, bu islem 1-2 dakika surebilir...
echo.

set /a BULUNAN=0
set "LISTE=%TEMP%\ag_radar.txt"
if exist "%LISTE%" del "%LISTE%"

for /l %%i in (1,1,254) do (
    title [ NETWORK RADAR ] Taraniyor: %AG%.%%i
    ping -n 1 -w 300 %AG%.%%i | find "TTL=" >nul
    if not errorlevel 1 (
        echo [+] Canli cihaz: %AG%.%%i
        echo %AG%.%%i>>"%LISTE%"
        set /a BULUNAN+=1
    )
)

title [ NETWORK RADAR ] Tarama tamamlandi
echo.
echo [*] Tarama tamamlandi. Canli cihaz sayisi: %BULUNAN%
echo.
echo [*] ARP tablosu ^(IP ve fiziksel adres eslesmeleri^):
echo.
arp -a | findstr /r /c:"^ *%AG%\."
echo.
echo [i] Canli cihaz listesi: %LISTE%
echo [i] Tanimadiginiz bir cihaz varsa yonlendirici panelinden Wi-Fi
echo     parolasini degistirin ve bagli cihaz listesini kontrol edin.
echo.
pause
exit /b 0

:ag_yok
echo [-] Aktif bir ag baglantisi bulunamadi.
echo.
pause
exit /b 1

Kod nasıl çalışıyor?

  • Ağ bulma: PowerShell ile varsayılan ağ geçidi olan bağlantının IPv4 adresi alınır. 192.168.1.23 adresinden ilk üç parça (192.168.1) ayrılarak tarama öneki oluşturulur.
  • Tarama döngüsü: for /l %%i in (1,1,254) 1'den 254'e kadar sayar. Her adrese ping -n 1 -w 300 ile tek paket ve en fazla 300 ms bekleme uygulanır.
  • Canlı cihaz tespiti: find "TTL=" komutu yalnızca gerçek ping yanıtlarında bulunan TTL= ifadesini arar; "ulaşılamıyor" yanıtları sayılmaz.
  • ARP tablosu: Ping atılan cihazlar ARP tablosuna işlenir. arp -a çıktısı findstr ile yalnızca bu ağın adresleriyle sınırlanır.
  • Pencere başlığı: title komutu her adreste güncellenir; böylece ekran yüzlerce satırla dolmaz.

Sonuçların yorumlanması

  • Her cihazın MAC adresinin ilk altı hanesi üreticiyi gösterir; adres maclookup.app gibi hizmetlerde aranarak cihaz türü tahmin edilebilir.
  • Bazı cihazlar (güvenlik duvarı olan bilgisayarlar, uyku modundaki telefonlar) ping yanıtlamayabilir; bu nedenle liste kesin değil, bir tahmindir.
  • Tanınmayan bir cihaz bulunduğunda yönlendirici panelindeki bağlı cihaz listesi kontrol edilmeli, Wi-Fi parolası değiştirilmelidir.
Bu araç yalnızca sahibi olunan veya yazılı izin alınmış ağlarda kullanılmalıdır. İzinsiz ağ taraması birçok ülkede suçtur. Betik ağdaki hiçbir cihaza erişmez, yalnızca ping gönderir.

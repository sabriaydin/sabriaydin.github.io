"İnternet gitti" dediğinde sorun üç yerden biri olabilir: bilgisayar-modem arası, modem-internet arası ya da alan adı çözümleme (DNS). Bu program üçünü sırayla dener, sonucu sade bir Türkçe yorumla söyler ve ayrıntılı bir rapor dosyasını masaüstüne kaydeder. Destek hattını arayacaksan bu raporu paylaşmak işini hızlandırır.

Nasıl kullanılır?

  1. Kodu ag-kontrol.bat adıyla kaydet.
  2. Çift tıkla. Özet birkaç saniyede ekrana gelir; ayrıntılı rapor en fazla yarım dakikada hazırlanır.
  3. Sonunda raporu hemen açabilirsin. Dosya masaüstünde ag_raporu.txt adıyla kalır.
@echo off
setlocal
title Ag Tanilama Raporu

rem Masaustu klasorunu bul (OneDrive kullananlarda yeri farkli olabilir)
for /f "delims=" %%d in ('powershell -NoProfile -Command "[Environment]::GetFolderPath('Desktop')"') do set "MASAUSTU=%%d"
set "RAPOR=%MASAUSTU%\ag_raporu.txt"

echo Ag kontrol ediliyor, lutfen bekle...
echo.

rem 1) Internete cikis var mi? (IP adresine ping; -4 = IPv4 kullan)
set "INTERNET=YOK"
ping -4 -n 2 8.8.8.8 | find "TTL=" >nul && set "INTERNET=VAR"

rem 2) Alan adlari cozuluyor mu? (DNS)
set "DNS=CALISMIYOR"
ping -4 -n 2 google.com | find "TTL=" >nul && set "DNS=CALISIYOR"

rem 3) Modemin adresini (varsayilan ag gecidi) bul
set "GW="
for /f "tokens=3" %%g in ('route print 0.0.0.0 ^| findstr /r /c:"^ *0\.0\.0\.0  *0\.0\.0\.0"') do if not defined GW set "GW=%%g"

rem 4) Modeme ulasilabiliyor mu?
set "MODEM=ULASILAMIYOR"
if defined GW (
    ping -4 -n 2 %GW% | find "TTL=" >nul && set "MODEM=ULASILIYOR"
)

echo ==========================================
echo              AG DURUMU OZETI
echo ==========================================
echo  Modem adresi        : %GW%
echo  Modeme erisim       : %MODEM%
echo  Internete cikis     : %INTERNET%
echo  Alan adi cozumleme  : %DNS%
echo ==========================================
echo.

if "%INTERNET%"=="VAR" if "%DNS%"=="CALISIYOR" goto :saglikli
if "%INTERNET%"=="VAR" goto :dns_sorunu
if "%MODEM%"=="ULASILIYOR" goto :internet_yok
goto :modem_yok

:saglikli
echo YORUM: Baglantin saglikli gorunuyor.
goto :rapor

:dns_sorunu
echo YORUM: Internete cikiliyor ama alan adlari cozulemiyor, yani DNS sorunu var.
echo ONERI: Yonetici komut isteminde "ipconfig /flushdns" yaz. Duzelmezse
echo        DNS sunucusunu 8.8.8.8 veya 1.1.1.1 olarak degistir.
goto :rapor

:internet_yok
echo YORUM: Modemine ulasiliyor ama internet yok. Sorun operatorde veya modemde.
echo ONERI: Modemi 30 saniye kapatip yeniden ac. Duzelmezse operatoru ara.
goto :rapor

:modem_yok
echo YORUM: Modemine bile ulasilamiyor.
echo ONERI: Wi-Fi acik mi, kablo takili mi, modem isiklari yaniyor mu kontrol et.
goto :rapor

:rapor
echo.
echo Ayrintili rapor hazirlaniyor, bu yarim dakikaya kadar surebilir...
(
    echo ===== AG RAPORU =====
    echo Tarih           : %date% %time%
    echo Bilgisayar      : %COMPUTERNAME%
    echo Modem adresi    : %GW%
    echo Modeme erisim   : %MODEM%
    echo Internete cikis : %INTERNET%
    echo DNS             : %DNS%
    echo.
    echo ===== IP AYARLARI =====
    ipconfig /all
    echo.
    echo ===== PING: 8.8.8.8 =====
    ping -4 -n 4 8.8.8.8
    echo.
    echo ===== ALAN ADI SORGUSU: google.com =====
    nslookup google.com
    echo.
    echo ===== YOL TAKIBI: 8.8.8.8 =====
    tracert -d -h 12 -w 1000 8.8.8.8
) > "%RAPOR%" 2>&1

echo.
echo Rapor kaydedildi:
echo %RAPOR%
echo.
choice /c EH /n /m "Rapor simdi acilsin mi? (E/H) "
if errorlevel 2 exit /b 0
start "" notepad "%RAPOR%"
exit /b 0

Kod nasıl çalışıyor?

  • Ping ile test: ping ... | find "TTL=" yanıt gelip gelmediğini anlar. "TTL=" ifadesi Windows'un hangi dilde olduğundan bağımsız olarak yanıtlarda yer alır. -4 ise IPv6 yerine IPv4 kullanır; çünkü IPv6 yanıtlarında TTL yazmaz.
  • &&: Soldaki komut başarılıysa sağdaki çalışır. Yani find "TTL=" bulursa durum VAR olur, bulamazsa varsayılan YOK kalır.
  • Üç ayrı test: 8.8.8.8 bir IP adresidir ve DNS gerektirmez. google.com ise DNS gerektirir. İkisi arasındaki fark sorunun DNS olup olmadığını gösterir.
  • Modem adresi: route print yönlendirme tablosunu yazar; 0.0.0.0 hedefli satırın 3. sütunu varsayılan ağ geçididir. Bu yöntem Windows dilinden etkilenmez.
  • Rapor bloğu: ( ... ) > dosya 2>&1 yapısı, parantezin içindeki tüm komutların çıktısını tek dosyaya yazar. Hata mesajları da (2>&1) dosyaya girer.
  • Yorum bölümü: if ... if ... goto art arda yazılınca "ve" anlamı taşır. Sırayla her durum kontrol edilir ve ilk uyan bölüme gidilir.

Özelleştirme

  • Farklı bir siteyi sınamak için google.com yerine kendi sitenin adresini yaz.
  • Rapora Wi-Fi bilgisi eklemek için blok içine netsh wlan show interfaces satırı ekleyebilirsin.
Dikkat: Bazı modemler ping yanıtını kapatır. "Modeme erişim: ULAŞILAMIYOR" yazsa bile internet çalışıyorsa sorun yoktur; yorum her zaman INTERNET sonucuna öncelik verir. Rapor IP ve bilgisayar adı gibi bilgiler içerir; herkese açık bir yerde paylaşmadan önce göz at.
